第13课时云计算安全概述
教学目标：了解信息安全三要素（CIA）；理解云计算面临的安全挑战；认识云安全与传统安全的区别
重点难点：重点=信息安全CIA三要素；难点=理解云安全责任共担模型
内容要点 （PPT: 第5章 P1-P8）
  • 信息安全三要素：机密性(Confidentiality)、完整性(Integrity)、可用性(Availability)
  • 云计算安全面临的独特挑战：多租户、数据外存、API风险
  • 云安全责任共担模型：云厂商负责基础设施安全，用户负责数据和应用安全
  • 生活中的安全类比：租房子——房东负责房屋结构安全，租客负责自己财物安全

第15课时对称加密算法（DES与AES）
教学目标：理解对称加密的工作原理；了解DES和AES算法的特点；掌握对称加密的优缺点
重点难点：重点=对称加密原理和特点；难点=理解密钥保管问题（密钥分发难题）
内容要点 （PPT: 第5章 P17-P24）
  • 对称加密原理：加密和解密使用同一把密钥
  • DES算法：56位密钥，已被淘汰（暴力破解只需数小时）
  • AES算法：128/192/256位密钥，当前标准，安全性高
  • 对称加密优点：速度快、适合大量数据加密
  • 对称加密缺点：密钥分发难题——如何安全地把钥匙给对方？

第16课时非对称加密算法（RSA）
教学目标：理解非对称加密的原理；了解公钥和私钥的关系；认识RSA算法的基本思想
重点难点：重点=公钥加密/私钥解密的原理；难点=理解"两把钥匙"的数学关系
内容要点 （PPT: 第5章 P25-P32）
  • 非对称加密原理：公钥加密、私钥解密（或私钥签名、公钥验证）
  • 公钥和私钥：公钥可以公开给所有人，私钥自己保管
  • RSA算法：基于大数分解难题（两个大素数相乘容易，分解回两个素数极难）
  • 非对称加密优点：解决了密钥分发难题
  • 非对称加密缺点：速度慢，不适合大量数据加密
  • 混合加密：用非对称加密传对称密钥，用对称加密传数据（HTTPS就是这么做的）

第17课时哈希算法与数字签名
教学目标：理解哈希算法的特点和用途；了解MD5和SHA算法；掌握数字签名的原理和作用
重点难点：重点=哈希算法的不可逆性和数字签名原理；难点=理解哈希与加密的区别
内容要点 （PPT: 第5章 P33-P40）
  • 哈希算法：将任意长度数据变成固定长度的"指纹"（摘要）
  • 哈希特点：不可逆（不能从摘要还原原文）、唯一性（不同数据哈希值不同）、确定性（同一数据哈希值不变）
  • 常见哈希算法：MD5（128位，已不安全）、SHA-256（256位，当前推荐）
  • 哈希应用：密码存储（不存明文存哈希）、文件完整性校验
  • 数字签名：用私钥对哈希值加密，用公钥验证——证明"是你发的"且"没被改过"
  • 生活类比：哈希=按手印（每个手指印独一无二但不能还原手指），数字签名=盖章+手印

第18课时数字证书与PKI
教学目标：理解数字证书的作用和结构；了解CA机构和PKI体系；认识证书在HTTPS中的应用
重点难点：重点=CA的作用和数字证书的概念；难点=理解PKI信任链
内容要点 （PPT: 第5章 P41-P48）
  • 数字证书：由权威机构（CA）签发的"网络身份证"
  • CA（Certificate Authority）：受信任的第三方机构，负责颁发和管理证书
  • PKI（公钥基础设施）：CA + 证书 + 密钥管理的完整体系
  • 证书内容：持有者信息、公钥、CA签名、有效期
  • 信任链：根CA → 中间CA → 终端证书，逐级验证
  • 生活类比：数字证书=身份证，CA=公安局，PKI=整个户籍管理系统

第19课时SSL/TLS与HTTPS
教学目标：理解SSL/TLS协议的作用；了解HTTPS的工作流程；认识加密技术在HTTPS中的综合应用
重点难点：重点=HTTPS的握手流程；难点=理解非对称加密、对称加密、数字证书在HTTPS中的配合使用
内容要点 （PPT: 第5章 P49-P56）
  • SSL/TLS协议：在HTTP基础上添加加密层，保护数据传输安全
  • HTTPS = HTTP + SSL/TLS
  • HTTPS握手流程：①客户端请求→②服务器返回证书→③客户端验证证书→④协商对称密钥→⑤加密通信
  • 综合应用：非对称加密传密钥、对称加密传数据、数字证书验身份、哈希校验完整性
  • 浏览器中的安全标识：锁头图标=HTTPS连接

第20课时云安全防护技术
教学目标：了解防火墙、IDS/IPS等网络安全设备；认识云环境中的访问控制和数据安全措施
重点难点：重点=防火墙和IDS/IPS的基本概念；难点=理解云环境中的多层安全防护
内容要点 （PPT: 第5章 P57-P64）
  • 防火墙：网络大门的保安，按规则放行或拦截流量
  • IDS（入侵检测系统）：监控网络异常，只报警不拦截（像监控摄像头）
  • IPS（入侵防御系统）：检测并主动拦截攻击（像保安直接出手）
  • 访问控制（IAM）：谁能访问什么资源，能做什么操作
  • 数据安全：数据加密存储、数据脱敏、备份恢复
  • 云安全防护体系：网络层→主机层→应用层→数据层，多层纵深防御

第38课时虚拟化原理与Hypervisor
教学目标：理解Hypervisor的概念和分类；了解Type 1和Type 2的区别；认识虚拟机的组成

内容要点 （PPT: 第9章 P15-P28）
  • Hypervisor（虚拟机监视器/VMM）：管理虚拟机的软件层
  • Type 1（裸金属）：直接运行在硬件上，如VMware ESXi、Hyper-V（性能好）
  • Type 2（宿主型）：运行在操作系统上，如VMware Workstation、VirtualBox（易用）
  • CPU虚拟化：时间片轮转，多个虚拟机共享物理CPU
  • 内存虚拟化：虚拟机看到的是连续内存，实际映射到物理内存的不同区域
  • 虚拟机组成：虚拟CPU、虚拟内存、虚拟磁盘、虚拟网卡
  • 生活类比：Type 1=直接在地基上盖楼（效率高），Type 2=在已有楼上加层（方便但稍慢）

教案使用说明

1. 本教案覆盖第13-72课时（共60课时），按12课时一个单元组织，共5个单元。

2. 每课时90分钟，采用"教师讲授+B站视频播放+纸面活动"模式，无上机环节。

3. 视频链接均为B站在线资源，需教室联网播放。建议教师课前试看并记录关键时间点。

4. 纸面活动包括：填表、画图、选择题、判断题、简答题、思维导图等，无需学生使用电子设备。

5. 教师演示环节：教师在大屏幕上操作，学生观看学习（如VMware操作、Linux命令、云控制台等）。

6. 每个单元结束有综合测试和思维导图，第六单元包含模拟考试和期末考试。

7. 教师可根据实际进度灵活调整视频播放时间和讲授内容。
