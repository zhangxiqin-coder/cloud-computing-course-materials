# 职高《云计算基础》72 课时全套教学资料

> 配套教材：《云计算基础技术与应用（第 2 版）（微课版）》  
> 易海博、池瑞楠 著，人民邮电出版社，ISBN 9787115664570  
> 适用对象：**职业高中**学生（课堂形态：教师演示 + 视频播放 + 纸质活动，无学生上机）

本仓库收录一套可直接用于上课的完整教学包，按"教、学、考、辅"四层组织。

## 目录结构

| 目录 | 内容 |
|------|------|
| `00_课程总纲与进度/` | 教学总纲（课程定位、三维目标、考核方案）与 18 周学期进度表 |
| `01_教案/` | 前 12 课时教案 + 第 13–72 课时教案（按 5 单元组织，含视频链接、教师演示、纸质活动） |
| `02_课堂习题与答案/` | 每课时 12 题课堂习题 PPT（共 864 题）+ 答案与解析 HTML |
| `03_单元测验与期中期末/` | 6 套单元测验 + 期中 + 期末，共 7 套可打印试卷及答案 |
| `04_知识导图与重难点/` | 章节知识导图（生活类比可视化）+ 重难点与易错点教师提示卡 |
| `06_改版课件PPT/` | 改版后的 3 个课件（加思考题 + NIST 3-5-4 渐进展示） |
| `99_脚本源码/` | 所有资料自动生成脚本（python-pptx / yt-dlp 等） |

## 使用说明

- **教案（HTML）**：用浏览器或 Chrome + MarkView 扩展直接打开即可，无需转换。
- **课堂习题（PPTX）**：用 PowerPoint / WPS 打开，投屏让学生作答；答案在对应 `*答案与解析.html`。
- **单元测验（HTML）**：可打印，含"一键隐藏答案"便于课堂小测。
- **视频素材**：本仓库**不含** 23 个 B 站下载视频（体积约 1.1GB），请使用本地离线副本；在线观看链接已嵌入教案 HTML 中。

## 资料规模

- 教案：72 课时全覆盖
- 课堂习题：72 × 12 = **864 题**
- 单元测验：7 套（含期中、期末）
- 知识导图：6 张 / 教师提示卡：6 单元
