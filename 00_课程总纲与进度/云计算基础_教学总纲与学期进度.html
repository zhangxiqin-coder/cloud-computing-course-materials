《云计算基础》课程教学总纲与学期进度计划

适用对象：职业高中（职高）学生 · 教材：《云计算基础技术与应用（第2版）（微课版）》ISBN 9787115664570 · 建议每章 4 课时、1 章 / 周

一、课程定位与学情说明

本课程是面向职业高中学生的专业基础课。学情与课堂形态经多轮调整后确定为以下三点，已贯穿全部配套资料设计：
  • 机房上课 学生在机房上课，人手一台电脑，可动手操作，不再是纯观看 + 纸面记录。
  • 机房预装 机房电脑按需预装 Windows 软件（Wireshark / MySQL / XAMPP·Apache+PHP，Git 可选），所有实操在 Windows + 浏览器 完成；凡需 Linux 的章节（第4/9/10章）由教师在阿里云演示（学生观看，机房不装 Linux），不装 VMware。
  • 视频多播 沿用"教师少讲、视频多播"：每节课教师讲授约 15–20 分钟，其余由视频与机房实操填充。
因此本课程的落地形态是：原始教材 PPT（教师直接拿来上课，不做修改）+ 每章配套"章节教学补充包"（重难点 / 易错点 / 随堂练习 / 上机实操）+ 视频素材 + 单元测验 / 知识导图。

二、课程目标（三维）

维度目标描述
知识与认知理解云计算基本概念（NIST 3-5-4 框架）、服务模型（IaaS/PaaS/SaaS）、部署模型（公有/私有/混合/社区）；了解云安全、网络、数据库、虚拟化、Linux、Web 服务与主流公有云/私有云平台。
能力与运用能结合生活类比解释云概念；能在网页工具中完成基础实操（建云文档、开在线终端、跑在线 SQL、查看 HTTPS 证书等）；能区分不同服务/部署模型适用场景；能完成随堂练习与纸面化配置练习。
素养与职业建立"云安全责任意识"（责任共担模型）；培养信息安全与密码学常识；激发对云计算产业的兴趣，为后续专业方向打基础。

四、考核评价方案

职高课程重在"过程可见、人人有得"。采用过程性评价为主的方案（可按学校要求微调比例）：
项目占比说明
平时成绩30%课堂出勤 + 每章随堂练习完成情况 + 机房实操验收清单（由教师随堂记录）
单元测验20%可按章组合为阶段性测验，见 03_单元测验与期中期末
期末考试50%全课程综合，第 13 教学周后安排（仅期末，不安排期中）

七、给同行的使用建议

  • 开课前：把 09_章节教学补充包 与 bilibili_videos 拷到 U 盘；确认机房电脑能联网（实操依赖网页工具），并提前在自己机器上跑一遍网页工具确认可用。
  • 每章节奏：先讲"重难点与易错点" → 放视频 → 做"随堂练习"当堂对答案 → 机房实操（按"上机实操.html"的步骤与验收清单完成）。
  • 每章末：用随堂练习 + 验收清单记录过程成绩；可按需从 03 抽取组合成阶段性小测。
  • 复习阶段：用 04 的知识导图做"一张图串全章"，配合期末综合卷查漏补缺。
  • 机房纪律红线：涉及云厂商页面只看不买、下课前必须退出登录、弹"保存密码"一律选"从不"。
