**用途**：向机房管理员提出的课前软件部署需求

## 三、教师端（阿里云）需准备

- **阿里云账号** + 一台按量付费 ECS（演示后释放，成本极低）：用于第4/9/10章演示，以及第12章控制台体验。
- 演示镜像建议：Ubuntu 22.04（第9/10章用）；演示时展示建实例、选规格、挂快照、SSH 登录、apt 装 vsftpd 等。
- 教师机本身也是 Windows，无需特殊软件（浏览器 + 阿里云控制台即可）。

---

## 四、机房环境要求（提给管理员）

1. **硬件**：每台 Windows 10/11 64 位；内存 ≥ 4GB 即可（不再跑本地虚拟机，门槛大降）；可用盘 ≥ 40GB。
2. **权限**：需管理员权限装 Wireshark / MySQL / XAMPP（一次性）。
3. **网络**：能上外网（Gitee、在线工具、阿里云控制台、draw.io 均依赖）；无需内网共享大镜像。
4. **统一母盘**：建议用同一镜像批量部署机房，保证三款软件版本一致。

## 五、说明（与教材的差异）

- 第3章教材原实战为 CloudSim（JDK8 + Eclipse + CloudSim），过重且偏离"部署模型"目标，已改为 **浏览器场景 + 拓扑设计**，零安装、目标更贴合。
- 第4/9/10章教材原实战为 VMware + Ubuntu 本地安装，已改为 **教师阿里云演示**，学生不装 Linux。
- 第12章教材原用腾讯云，为与演示保持一致改为 **阿里云**；学习目标（体验公有云控制台）不变。
- 以上改动只替换"实验工具 / 平台"，各章 **教学内容知识点** 仍严格以原版 PPT 为准。
