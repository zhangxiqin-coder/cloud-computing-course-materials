《云计算基础》重难点与易错点 · 教师随堂提示卡

每单元一卡：重点讲什么 · 学生常错什么 · 怎么提问 · 板书怎么写
第一单元 · 课时1-12 · 概念/服务/部署

云计算基础概念

★ 教学重点

  • NIST 3-5-4 框架（3服务/5特征/4部署）
  • IaaS/PaaS/SaaS 区别与例子
  • 4 种部署模型及适用场景
  • 云计算特点（按需、弹性、池化…）

⚠ 学生易错

  • 把 3/5/4 记反（常说成 3 特征）
  • 分不清 IaaS 和 PaaS（都“给平台”错觉）
  • 以为私有云一定更安全/更便宜
  • 把“云”等同于“网盘”

❓ 课堂提问话术

  • “你手机里哪些 App 其实是在‘云’上跑的？”
  • “租毛坯房、精装房、住酒店，分别像哪种云服务？”
  • “学校的内部系统，该用公有云还是私有云？”

📋 板书要点

  • 左：NIST 3-5-4 三段式框架图
  • 中：I/P/S 三层对比表（管什么/例子）
  • 右：4 部署模型 + 一句话场景
第二单元 · 课时13-24 · 安全/市场

云安全与云市场

★ 教学重点

  • CIA 三要素（机密/完整/可用）
  • 加密、哈希、数字签名的作用区别
  • 责任共担模型（厂商 vs 用户）
  • 国内主流云厂商（阿里/腾讯/天翼/华为）

⚠ 学生易错

  • 哈希当加密用（哈希不可逆！）
  • 以为“上云=厂商全包安全”
  • 分不清对称/非对称加密
  • DDoS 破坏的是“可用性”不是“机密性”

❓ 课堂提问话术

  • “文件被偷看、被改了、打不开，分别破坏 CIA 哪一条？”
  • “租房时，房东和租客各管什么安全？”
  • “为什么不能把存储桶设成‘公开’？”

📋 板书要点

  • CIA 三角 + 每角对应技术手段
  • 加密/哈希/签名 三栏对比
  • 责任共担：左右两列分清楚
第三单元 · 课时25-36 · 网络/数据库

计算机网络与数据库

★ 教学重点

  • IP 地址、DNS 域名解析
  • HTTP/HTTPS、路由器/交换机
  • 关系型数据库：表/行/列/主键
  • SQL 基本查询 SELECT

⚠ 学生易错

  • 把 DNS 当 IP 本身
  • 主键可以重复（错！必须唯一）
  • 混淆“字段”和“记录”
  • 以为 NoSQL 不是数据库

❓ 课堂提问话术

  • “输入网址到看到页面，中间发生了什么？”
  • “Excel 的表、行、列，对应数据库叫什么？”
  • “怎么一句话找到表里‘张三’那条记录？”

📋 板书要点

  • “输入网址→DNS→IP→HTTP→返回”流程图
  • 数据库：表结构图（主键标红）
  • SELECT 例句写在右侧
第四单元 · 课时37-48 · 虚拟化/Linux

虚拟化基础与 Linux

★ 教学重点

  • 虚拟化概念与 Hypervisor
  • 虚拟机、快照、迁移
  • Linux 常见命令（ls/cd/pwd/mkdir/rm）
  • 文件权限 rwx

⚠ 学生易错

  • rm -rf 当普通删除用（危险！）
  • 混淆 cd 和 ls 的用途
  • 以为虚拟机=一台真电脑（是软件模拟）
  • 权限 r/w/x 含义记混

❓ 课堂提问话术

  • “一栋楼隔成多个房间，像不像虚拟化？”
  • “我要看现在在哪个目录，用哪条命令？”
  • “删东西前为什么要先确认路径？”

📋 板书要点

  • 物理机 → Hypervisor → 多虚拟机 层级图
  • 命令速查表（5 条 + 一句话用途）
  • 权限 rwx 三位示例
第五单元 · 课时49-60 · Web/公有云

Web 服务与公有云

★ 教学重点

  • 网站上线链路：域名→DNS→ECS→Nginx
  • 对象存储 OSS/COS 用途
  • VPC、负载均衡、CDN、弹性伸缩
  • 按需付费模式

⚠ 学生易错

  • 把对象存储当数据库用
  • 以为 CDN 让网站更慢
  • 混淆 ECS 和对象存储
  • 不懂“弹性”为什么省钱

❓ 课堂提问话术

  • “双十一流量暴涨，传统机房和云谁更扛得住？为什么？”
  • “视频网站的大文件该存 ECS 还是对象存储？”
  • “为什么要做负载均衡？”

📋 板书要点

  • “网站上线全链路”箭头图
  • 公有云组件对照表（ECS/存储/VPC/LB/CDN）
第六单元 · 课时61-72 · 私有云/复习

私有云与综合复习

★ 教学重点

  • 私有云 vs 公有云 取舍
  • 课程全链路回顾（概念→技术→平台）
  • 综合卷查漏补缺

⚠ 学生易错

  • 复习时只背术语、不会串联
  • 混淆公有/私有/混合的适用场景
  • 简答题写太短、缺例子

❓ 课堂提问话术

  • “医院病历这种敏感数据，该放哪种云？”
  • “用一张图，把咱们学的云串起来”

📋 板书要点

  • 用知识导图 ⑥ 做整书串联
  • 红笔标出高频考点（3-5-4、CIA、ECS）
