一、单项选择题

1. 下列不属于数据管理技术主要经历阶段的是（　）。
答案：B
数据管理技术的三个阶段是人工管理、文件系统、数据库系统，没有「机器管理」阶段。
2. 数据库的概念模型独立于（　）。
答案：A
概念模型只描述信息世界的实体及其联系，与具体计算机、DBMS 无关。
3. 下列不属于关系完整性的是（　）。
答案：D
关系完整性包括实体完整性、参照完整性和用户定义完整性，没有「逻辑结构的完整性」。
4. 不同的数据模型是提供模型化数据和信息的不同工具，用于信息世界建模的是（　）。
答案：C
概念模型用于信息世界建模，E-R 图是概念模型的常用表示方法。
5. 下列关于数据库系统描述正确的是（　）。
答案：A
数据库系统通过数据结构化、共享和完整性控制减少冗余，但不能避免一切冗余；一致性不是指类型一致，而是指数据相互协调、不矛盾。
6. 下面哪个命令属于 SQL 授权命令？（　）
答案：D
grant 用于给用户或角色授予权限，是 SQL 的授权语句；update/delete/select 是数据操纵语句。

二、简答题

1. 简述数据库管理系统的功能。
答案：数据库管理系统（DBMS）的主要功能包括：① 数据定义：通过 DDL 定义数据库的结构、数据类型、完整性约束等。② 数据操纵：通过 DML 实现数据的查询、插入、删除、修改。③ 数据控制：通过 DCL 实现权限管理、并发控制、完整性检查、故障恢复与备份。④ 数据库的建立与维护：包括初始数据装入、性能监控、存储管理、重组与重构。⑤ 数据字典管理：记录数据库的元数据，供系统与用户查询。
从定义、操纵、控制、维护、数据字典五个角度回答。
2. 简述 SQL 的特点。
答案：SQL 的特点主要有：① 综合统一：集数据定义（DDL）、数据操纵（DML）、数据控制（DCL）于一体。② 高度非过程化：用户只需说明「要什么」，不必描述「怎么做」。③ 面向集合的操作方式：一条 SQL 语句可处理一组记录，而不是逐条处理。④ 语法简洁、易学易用：接近自然语言。⑤ 既可独立使用，也可嵌入到高级程序设计语言中使用。
关键词：综合统一、非过程化、集合操作、简洁、可嵌入。
3. 什么是数据库系统？
答案：数据库系统（DBS）是指在计算机系统中引入数据库后的完整系统，由数据库（DB）、数据库管理系统（DBMS）、应用系统、数据库管理员（DBA）和用户组成。其中数据库是长期存储在计算机内、有组织、可共享的数据集合；DBMS 是管理和维护数据库的核心软件；DBA 负责数据库的规划、设计、维护和优化。
强调数据库系统不仅仅是数据库本身，还包括软件、人员和应用。
4. 说明数据库完整性保护的主要任务和措施。
答案：主要任务：防止数据库中存在不符合语义的数据，保证数据的正确性、有效性和相容性。措施：① 定义完整性约束：通过主键、外键、唯一约束、检查约束等机制在模式定义时固化规则。② 实体完整性：主键不能为空、不能重复。③ 参照完整性：外键必须对应被参照表的有效主键，防止出现孤立记录。④ 用户定义完整性：根据业务规则设置 check 约束、触发器等。⑤ 运行期检查：DBMS 在插入、删除、修改时自动校验约束，违反时拒绝执行。
任务讲「保证正确有效相容」，措施讲「三类完整性 + 约束定义 + 运行期检查」。
5. 假设你在设计一个数据库系统时面临性能和一致性的权衡，你会如何在确保 ACID 原则的同时优化性能？
答案：在确保 ACID 的前提下优化性能可从以下方面入手：① 合理设计索引：在频繁查询和连接条件的列上建立索引，加快检索，但避免过多索引拖慢写入。② 优化 SQL 语句：避免全表扫描、减少不必要的连接、使用覆盖索引。③ 规范化与反规范化平衡：高范式减少冗余但可能增加连接，必要时对读多写少的场景做适度反规范化。④ 事务控制粒度：在保证一致性的前提下，尽量缩短事务长度、降低锁粒度，减少并发冲突。⑤ 缓存与读写分离：对热点数据加缓存，对读多写少的业务做主从分离。⑥ 选择合适的存储引擎与隔离级别：根据业务特点在一致性和并发度之间取舍。
核心是「不牺牲 ACID 底线，但在索引、SQL、范式、事务、缓存、架构上做优化」。
6. 关系数据库和非关系数据库在数据结构、查询语言、性能等方面有哪些差异？
答案：数据结构：关系数据库用二维表（行和列）组织数据，模式严格；非关系数据库采用键值、文档、列族、图等多种灵活结构。查询语言：关系数据库使用 SQL，查询标准化、表达能力强；非关系数据库多使用各自专门的 API 或类 SQL 语法，灵活性高但缺乏统一标准。一致性：关系数据库强调 ACID 强一致性；非关系数据库多追求 BASE 最终一致性，适合高并发分布式场景。性能：关系数据库在复杂事务、关联查询上表现好；非关系数据库在大规模横向扩展、高吞吐读写、半结构化数据处理上更有优势。
从结构、查询语言、一致性、性能四个维度对比，可结合具体类型（如 MySQL vs MongoDB）举例。
7. 假设你正在开发一个需要处理大量实时数据的系统，你会选择哪种类型的非关系数据库？说明你的选择理由。
答案：可选择列族数据库（如 HBase、Cassandra）或流式处理数据库/时序数据库。理由：处理大量实时数据通常具有高并发写入、数据量大、时间序列明显的特点。列族数据库支持水平扩展和高吞吐写入，适合日志、传感器数据、点击流等场景。时序数据库针对时间戳数据优化，写入和按时间范围查询效率高。如果数据之间存在复杂关系，也可考虑图数据库。具体选择要结合数据特征、一致性要求、查询模式来决定。
开放题，言之成理即可；推荐答「列族数据库/时序数据库 + 水平扩展 + 高吞吐写入」。
8. 一个现代化数据中心的网络架构应该具备哪些关键特征？
答案：关键特征包括：① 高可用与冗余：核心交换、路由、链路双活或多活，避免单点故障。② 高带宽与低时延：东西向流量（服务器之间）越来越大，需要高速互联和低时延网络。③ 可扩展性：支持模块化、横向扩展，能随业务增长灵活增加机柜与带宽。④ 安全性：网络分区、访问控制、入侵检测、流量审计，管理面与数据面隔离。⑤ 自动化与可编程：支持 SDN、自动化配置、流量调度和可视化运维。⑥ 绿色节能：采用冷热通道、液冷、自然冷却等技术降低 PUE。
从可用性、带宽、扩展、安全、自动化、节能六个角度作答。
9. 你认为数据中心与云计算在现代 IT 基础设施中各扮演什么角色？
答案：数据中心是物理基础设施：提供机房、电力、制冷、网络、服务器、存储等硬件资源，是 IT 系统的载体。云计算是服务化交付模式：通过网络把数据中心的计算、存储、网络、平台、软件等资源以服务的形式按需提供给用户。两者关系：云计算依赖数据中心作为底层资源池；数据中心则通过云计算技术实现资源池化、弹性调度和高效运营。数据中心关注「物理资源怎么建、怎么管」，云计算关注「资源怎么按需交付、怎么计量收费」。
用一句话概括：数据中心是「地基」，云计算是「按需卖房子/租房子的商业模式」。
