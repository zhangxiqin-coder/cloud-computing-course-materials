上机实操指导

机房环境：可上网、不可安装软件，全部实操基于网页 / 在线工具 / 系统自带命令

机房纪律：① 一律不安装任何软件，网站要求下载客户端时点「网页版」；② 涉及云厂商页面只看不买，绝不点付款；③ 下课前必须退出登录，浏览器问「是否保存密码」一律选「从不」。
实验一：在线 SQL 体验（替代本机安装数据库）
目标：在不安装任何软件的情况下，体验 SQL 查询、插入、更新、删除。
操作步骤：
  1. 打开在线 SQL 练习网站 https://sqlzoo.net/（或 https://sqliteonline.com/）。
  2. 选择 SELECT 基础练习，执行 SELECT * FROM xxx LIMIT 5; 查看数据。
  3. 尝试 WHERE 条件查询和 ORDER BY 排序。
  4. 用 INSERT、UPDATE、DELETE 各完成一次操作，观察数据变化。
验收清单：
  • 成功执行 SELECT 查询
  • 用过 WHERE 和 ORDER BY
  • 完成增删改各一次
打不开 / 完不成：sqlzoo 页面是英文，重点看 SQL 代码；若打不开可换 sqliteonline。
实验二：用在线工具画 E-R 图（概念模型）
目标：理解实体、属性、联系，设计一个简单的数据库概念模型。
操作步骤：
  1. 打开在线流程图工具 https://processon.com/（或腾讯文档的插入图形功能）。
  2. 设计一个小场景：学生选课系统。
  3. 画出实体：学生、课程；属性：学号、姓名、课程号、课程名；联系：选课（多对多）。
  4. 用矩形表示实体，椭圆表示属性，菱形表示联系。
验收清单：
  • 画出至少 2 个实体
  • 标出关键属性
  • 正确表达学生与课程的多对多联系
打不开 / 完不成：工具只是载体，重点是 E-R 三要素画对。
实验三：数据库完整性约束在线体验
目标：通过在线数据库工具观察主键、唯一约束的作用。
操作步骤：
  1. 打开 https://sqliteonline.com/。
  2. 建表并指定主键：CREATE TABLE t(id INTEGER PRIMARY KEY, name TEXT);
  3. 插入两条相同 id 的记录，观察是否报错（应报主键重复）。
  4. 再插入一条 id 为空/NULL 的记录，观察是否报错。
验收清单：
  • 成功建表
  • 主键重复时报错
  • 理解主键不能为空/不能重复
打不开 / 完不成：不同在线工具错误提示不同，重点是理解约束效果。
