第 10 章 · Linux基础
重难点与易错点

对应 教材 PPT：10.Linux基础.pptx（77 页）｜ 课本 10.10 思考与练习 p.157–158

一、本章重点（必须掌握）

重点1
UNIX 与 Linux：UNIX 最早由 Ken Thompson、Dennis Ritchie 等于 1969 年在 AT&T 贝尔实验室开发，只有符合单一 UNIX 规范的系统才能叫 UNIX，否则称为类 UNIX；Linux 是一套免费使用、自由传播的类 UNIX 操作系统，基于 POSIX 和 UNIX，是多用户、多任务、支持多线程和多 CPU 的操作系统。
重点2
Linux 的两条基本思想：一切都是文件；每个软件都有确定的用途。它的特性还包括完全免费、完全兼容 POSIX 1.0 标准、多用户多任务、字符界面与图形界面（X-Window）并存、支持多种硬件平台。
重点3
Linux 文件类型：纯文本文件（ASCII）、二进制文件、数据格式文件、目录、连接文件、设备与设备文件（块设备 / 字符设备）、套接字（sockets）、管道（FIFO）。
重点4
Linux 文件结构是树状目录：/ 根目录、/bin 常用命令、/sbin 系统管理命令、/etc 配置文件、/dev 设备文件、/proc 内存中的系统信息、/var 变动数据与日志、/usr 占用空间最大、/home 普通用户主目录、/lib 共享库、/opt、/mnt、/media、/srv。
重点5
FTP 服务与 DNS：FTP 采用客户 / 服务器结构，命令端口 21、数据端口 20，分主动 PORT 与被动 PASV 两种模式，还有不要求注册的匿名 FTP、基于 UDP 的 TFTP；DNS 是 Internet 上把域名和 IP 地址相互映射的分布式数据库，主机名到 IP 有静态映射与动态映射两种方式，解析时通常先查静态、再走动态。

二、本章难点（讲慢一点、配比喻）

难点1
文件目录职责最容易混：配置文件在 /etc、内存中的系统信息在 /proc、日志与变动数据在 /var、共享库在 /lib、额外工具在 /usr、用户主目录在 /home，需要成组对比讲。
难点2
FTP 主动模式（PORT）与被动模式（PASV）要讲清「两条连接」：21 端口走命令，数据走 20 端口（主动）或服务器高端口（被动），这也解释了为什么防火墙后面的客户端常常连不上。
难点3
静态映射与动态映射的区别：静态是每台设备各自维护、只供本机使用的映射表；动态是专门的 DNS 服务器统一维护、全网查询。为什么「先静态、再动态」也要点明。

三、易错点（学生常错，务必提前点破）

易错1
把 Linux 当成免费的 Windows——Linux 的核心是「一切都是文件」，配置靠文本文件，而不是注册表。
易错2
以为 /proc 下是真实文件——它是内存中由系统产生的虚拟信息，重启即变（对应课本第 6 题）。
易错3
混淆 ls 的参数：-a 显示全部文件（含 . 开头的隐藏文件），-l 是长格式（权限、属主、大小、时间），-d 只显示目录本身。
易错4
以为 FTP 只用一个端口——命令走 21，数据走 20 或高端口；TFTP 更是基于 UDP。
易错5
把「改 hosts 文件」当成解决一切解析问题——hosts 只是静态映射，上网主要靠 DNS 动态映射。
教师提示：建议把「易错点」单独投一屏，讲完知识点后立刻点破，比事后订正有效得多。
