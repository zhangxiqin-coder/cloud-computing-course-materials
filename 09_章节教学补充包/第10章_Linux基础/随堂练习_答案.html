一、单项选择题

1. 在创建 Linux 分区时，一定要创建（　　）两个分区。
答案：D
Linux 至少要划分根分区（/）和交换分区（swap）才能正常安装运行：根分区存放系统与数据，swap 用于虚拟内存。FAT、NTFS 是 Windows 的文件系统，Linux 不会用它们作系统分区。
2. 在 Red Hat Linux 9 中，系统默认的（　　）用户对整个系统拥有完全的控制权。
答案：A
root 是 Linux/UNIX 的超级用户（UID 为 0），拥有系统最高权限。Administrator 是 Windows 里的叫法，Guest 是来宾账户。
3. 存放用户密码信息的目录是（　　）。
答案：B
/etc 存放系统配置文件，其中 /etc/passwd 与 /etc/shadow 保存用户账号与口令信息。/boot 放内核与引导文件，/var 放日志等变动数据，/dev 放设备文件。
4. 默认情况下，管理员创建了一个用户，就会在（　　）目录下创建一个用户主目录。
答案：B
普通用户的主目录是 /home/用户名；root 的主目录比较特殊，是 /root（不在 /home 下），这是常考的对比点。
5. 如果要列出一个目录下的所有文件，需要使用命令（　　）。
答案：C
-a 表示 all，会把 . 开头的隐藏文件也列出来；-l 是长格式显示，-d 只列目录本身。
6. 下面选项中，对 /proc 目录描述正确的是（　　）。
答案：A
/proc 是内存中的虚拟文件系统，反映内核与各进程的实时状态。B 说的是 /usr（额外工具），C 说的是 /boot（引导文件），D 说的是 /lib（共享库）——这四个目录的职责要成组记。
7. 除非特别指定，cp 命令要复制的文件在下面哪个目录下？（　　）
答案：D
不写路径时，命令默认在当前工作目录下寻找文件，用 pwd 可以查看当前所在目录。
8. 按（　　）组合键能终止当前运行的命令。
答案：A
Ctrl+C 发送中断信号，终止当前正在运行的命令；Ctrl+D 表示输入结束（EOF），常用来退出登录；Ctrl+Z 是挂起当前任务。
9. 用来启动 X Window 的命令是（　　）。
答案：C
教材答案文档标注为 C。注意 Linux 命令严格区分大小写，实际手写时是小写 startx，课堂上提醒学生别按 Windows 的习惯写大写。
10. 用来分离目录名和文件名的字符是（　　）。
答案：B
/ 是路径分隔符，同时也代表根目录；. 表示当前目录，.. 表示上一级目录；- 常出现在命令参数里，* 是通配符。

二、简答题

1. FTPS 或 SFTP 等是怎么增强 FTP 安全性的？
答案：传统 FTP 在传输过程中以明文传送用户名、密码和数据，容易被窃听和篡改。FTPS 是在 FTP 的基础上加入 SSL/TLS 加密层（FTP over SSL），为命令通道和数据通道都加上加密与服务器证书验证；SFTP 并不是 FTP 的加密版，而是基于 SSH 协议的文件传输子系统，认证与数据全部跑在 SSH 加密隧道里，默认使用 22 端口。二者都用「加密传输 + 身份验证」解决明文 FTP 的窃听与篡改风险，区别在于 FTPS 沿用 FTP 的端口、需要申请证书，SFTP 只需 SSH 服务、配置更简单。
答题主线：明文 FTP 的风险 → FTPS（SSL/TLS 加密 + 证书）→ SFTP（SSH 隧道，22 端口）→ 二者都用加密解决窃听与篡改。
2. 作为一名网络管理员，你会如何规划和管理公司的 DNS 服务以确保高可用性和性能？
答案：① 架构冗余：至少部署两台以上 DNS 服务器，一主一从（或多从）做区域传送，避免单点故障。② 内外分离：内网 DNS 只解析内部域名、外网 DNS 只发布必要的公网记录，防止内部信息泄露。③ 性能优化：合理设置 TTL、开启缓存，把常用域名写入静态映射或本地缓存，减少解析次数；必要时用就近解析或 DNS 负载均衡。④ 安全防护：限制允许做区域传送的对象，启用 DNSSEC 防篡改与缓存投毒，做查询日志审计与异常流量监控。⑤ 运维管理：统一命名规范、变更留档，定期演练主从切换。
答题四条主线：冗余（主从 + 区域传送）→ 内外分离 → 缓存与 TTL 提速 → 安全（限制传送 / DNSSEC）→ 运维留档。
3. 在管理 Linux 时会面临的主要挑战是什么？
答案：① 学习门槛：以命令行操作为主，命令与参数多、严格区分大小写（ls -a 与 ls -A 含义不同），习惯图形界面的用户上手慢。② 权限与安全：root 权限过大，滥用 root 容易误删系统文件，需要养成普通用户 + sudo 的习惯并管好文件权限。③ 目录结构差异：Linux 用树状目录、一切皆文件，与 Windows 的盘符体系完全不同，要熟悉 /etc、/var、/home 等目录职责。④ 软件与依赖：不同发行版包管理方式不同（apt、yum、dnf），离线环境还要解决依赖问题。⑤ 故障排查：服务、网络、权限问题往往要靠日志（/var/log）结合命令逐层定位。⑥ 兼容性：部分 Windows 软件没有 Linux 版本，需要寻找替代方案。
从「命令行门槛 / 权限安全 / 目录结构 / 软件依赖 / 排错 / 兼容性」六点谈，最好各举一个具体例子。
4. 在实际应用中，UNIX 和 Linux 哪个更适合用于企业级服务器环境？
答案：没有绝对答案，要看企业的实际需求。UNIX（如 AIX、HP-UX、Solaris）由厂商提供整体方案，稳定性与可靠性久经考验，技术支持与软硬件认证完善，适合金融、电信等对可用性要求极高的关键业务，但价格昂贵、硬件绑定、生态相对封闭。Linux（如 RHEL、CentOS、Ubuntu Server、麒麟等）免费开源，硬件兼容性好，社区活跃、生态丰富，对容器与云原生等新技术支持好，性价比高，是当前互联网企业与云平台的主流选择。综合来看，绝大多数企业级服务器环境（尤其是新建系统和上云场景）更适合选 Linux；只有已经深度使用 UNIX 且业务难以迁移的关键系统才继续保留 UNIX。
结论先给「看场景」，再对比：UNIX 赢在稳定性与服务保障、贵且封闭；Linux 赢在开源、生态、性价比与云原生支持，最后给出「新建系统优先 Linux」的判断。
5. 你认为 Linux 在云计算环境中扮演着什么角色？
答案：① 云计算的基础操作系统：绝大多数云服务器、容器与虚拟化平台的宿主系统都运行 Linux，云主机（ECS/CVM）的默认镜像也多为各类 Linux 发行版。② 虚拟化与容器技术的载体：KVM、Xen、Docker、Kubernetes 等核心组件都依赖 Linux 内核能力（命名空间、cgroups）实现。③ 开源生态的主力平台：OpenStack、Hadoop、Nginx、MySQL 等云上主流软件都首选运行在 Linux 上。④ 运维自动化的基础：Shell、Ansible 等工具让云上大批量服务器可以被统一批量管理。⑤ 成本优势：免费开源、对硬件要求低，契合云平台大规模部署的成本控制需求。可以说 Linux 是云计算的「地基」——用户手里的云主机、云上的容器和数据库，底层几乎都是 Linux。
答题主线：云主机的默认系统 → 虚拟化与容器的技术底座 → 开源软件的主流平台 → 自动化运维的载体 → 开源免费的成本优势。
