第10章 Linux基础 · 教案

教材：《云计算基础技术与应用(第2版)(微课版)》ISBN 978-7-115-66457-0

一、教学目的
  1. 了解 UNIX 与类 UNIX 操作系统的来龙去脉，理解 Linux 的诞生与定位——绝大多数云服务器跑的就是 Linux。
  2. 掌握 Linux 的文件类型与目录结构（一切皆文件、/ 根目录下的标准目录）。
  3. 认识 Ubuntu 发行版，以及 FTP 服务、域名系统（DNS）这两个与 Linux 服务器密切相关的网络服务。
  4. 第 3 课时在第 9 章装好的 Ubuntu 上安装 FTP 服务，第 4 课时独立完成本章随堂练习。
二、重点、难点及处理方法

教学重点：

  1. Linux 与 UNIX 的关系、Linux 的特点。
  2. Linux 文件类型（普通文件 / 目录 / 设备文件等）与目录结构（/、/home、/etc、/var 等）。
  3. FTP 服务与 DNS 的作用。

教学难点：

  1. 「一切皆文件」思想难理解——硬件设备也当成文件看待。
  2. Linux 目录结构（/、/home、/etc、/var、/usr）各自用途易混。
  3. FTP 与 DNS 的工作机制偏底层，初学者易困惑。

处理方法：

  • 用「一棵大树」比喻 Linux 目录结构——根是 /，各分支（home / etc / var）各管一摊事，比 Windows 的 C: D: 盘更统一。
  • 用「图书馆的索引 vs 快递柜」分别比喻 DNS（域名翻译成 IP）与 FTP（文件传输柜）。
  • 第 3 课时在真实 Ubuntu 上装 FTP，把「目录结构」「服务」「命令」一次性具象化。
三、教具

机房电脑 + 多媒体投影 第9章已装好的 Ubuntu 虚拟机（本课时在其上安装 FTP 服务） Linux 目录结构速查图（/ 及各子目录含义） 黑板 +「FTP / DNS 是什么」对照表

四、课时分配

1、 讲课：UNIX + Linux 操作系统 + Linux 文件类型和结构（1 课时）
2、 讲课：Ubuntu + FTP 服务 + 域名和域名系统 DNS（1 课时）
3、 实战：在 Ubuntu 上安装 FTP 服务（1 课时）
4、 随堂练习 + 讲解练习情况（1 课时）

五、作业

1、 完成随堂练习中当场未做完的题目（课本第 10 章「思考与练习」原题，教师投影题目或印发，学生纸上作答）。
2、 用一句话说明「为什么云服务器大多用 Linux」，并画出 / 根目录下 3 个你记住的子目录及其用途。
3、 整理第 3 课时在 Ubuntu 上安装 FTP 的 1 句操作记录。

六、教学过程
1
讲课：UNIX + Linux + 文件结构与类型
教材原版 PPT 第10章 4–45 页 ｜ 90 分钟
环节教学活动
引入教师：提问「你用的手机、网站背后的服务器，大多跑什么系统？Windows 吗？」引出 Linux 的统治地位。
讲解教师：讲 UNIX 与类 UNIX 系统的发展、Linux 的诞生与特点（开源、稳定、多用户多任务）；讲 Linux 文件类型与目录结构（一切皆文件、/ 根目录及 home / etc / var / usr 等标准目录）。
互动师生：全班口头接龙，每人说一个「你用过的开源软件 / 设备」（安卓、路由器、智能音箱），教师点出它们背后多半是 Linux / 类 UNIX，归类到黑板「Linux 无处不在」。
收口教师：小结 Linux 与目录结构；预告下节课讲 Ubuntu / FTP / DNS，之后在真机上装 FTP。
2
讲课：Ubuntu + FTP 服务 + DNS
教材原版 PPT 第10章 46–73 页 ｜ 90 分钟
环节教学活动
引入教师：提问「你输入 www.baidu.com，电脑怎么知道该连哪个 IP？文件怎么从一个电脑传给另一个？」
讲解教师：讲 Ubuntu 这一主流 Linux 发行版；讲 FTP 服务（文件传输协议，把文件像快递一样送来送去）；讲域名与域名系统 DNS（把 www.xxx.com 翻译成 IP 地址）。
互动师生：教师把「FTP / DNS 是什么」对照表画在黑板（作用、类比、典型应用），请学生口头补全，点破易错点（DNS 是翻译、FTP 是搬运，别混）。
收口教师：一句话总结「Linux + 网络服务 = 云服务器的日常」；点明下节课动手装 FTP。
3
实战：在 Ubuntu 上安装 FTP 服务
教材原版 PPT 第10章 74–76 页 ｜ 90 分钟
环节教学活动
布置教师：说明实战目标——在第 9 章装好的 Ubuntu 虚拟机上安装并启动一个 FTP 服务，体会「Linux 服务器跑网络服务」的真实流程，顺便复习目录结构与命令。无虚拟机 / 权限的机位由教师统一演示，学生记录。
实操电脑学生（分步完成）：
① 打开第 9 章的 Ubuntu 虚拟机并登录；
② 用包管理命令安装 FTP 服务（如 vsftpd）；
③ 启动服务并确认其运行；
④ 观察 FTP 相关目录与配置文件位置，回扣「一切皆文件」。
巡堂教师：走动答疑，收集典型问题（如命令报错、服务起不来），投屏演示；无环境的机位统一看教师机操作。
收口教师：请 1–2 组展示 FTP 服务运行状态，点出「你刚让一台 Linux 服务器具备了传文件的能力」。要求每人留 1 句操作记录进笔记。
4
随堂练习 + 讲解练习情况
课本第10章「思考与练习」原题（教师投影 / 印发）｜ 90 分钟
环节教学活动
练习学生：完成课本第 10 章「思考与练习」原题（教师投影题目或印发，学生作答于作业本）。教师计时，约 35–40 分钟独立完成。
收看教师：巡堂收看完成情况，标记错误率高的题目（通常集中在目录结构、FTP / DNS 区分）。
讲解教师：挑选错误率最高的 6–8 题重点讲解，公布答案要点，让学生对照订正。
收口教师：回扣本章易错点做总结；未做完的题作为作业补完。
七、课后小结
人工智能241班：应到 42 人，实到 42 人。课时 1–2 Linux 定位、目录结构达成度较好，大树比喻接受快；「一切皆文件」、FTP / DNS 区分仍是难点。课时 3 Ubuntu 装 FTP 实战多数完成服务启动（约 4 组无虚拟机改看演示），连续 VMware 链条（第4/9/10章）让「云服务器日常」体感强。课时 4 随堂练习目录结构类题正确率约 80%，DNS / FTP 概念题失分较多，已现场重讲。下次：目录结构速查图、FTP/DNS 对照表提前发，安装前先演示命令。
