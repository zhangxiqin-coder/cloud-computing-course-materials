上机实操指导

机房环境：可上网、不可安装软件，全部实操基于网页 / 在线工具 / 系统自带命令

机房纪律：① 一律不安装任何软件，网站要求下载客户端时点「网页版」；② 涉及云厂商页面只看不买，绝不点付款；③ 下课前必须退出登录，浏览器问「是否保存密码」一律选「从不」。
实验一：在 Windows 本机做域名解析（对应教材图 10-21 / 10-22 的 host 与 nslookup）
目标：在自己的 Windows 电脑上完成一次域名解析，理解静态映射与动态映射、DNS 到底在干什么。
操作步骤：
  1. 按 Win+R 输入 cmd 回车，打开命令行。
  2. 执行 nslookup www.baidu.com，记下返回的 Server（DNS 服务器地址）和 Address（解析出的 IP）。
  3. 再执行 nslookup www.test.com，看解析失败的返回是什么样，体会「找不到域名」的提示。
  4. 执行 ping www.qq.com，观察域名被解析成哪个 IP。
  5. 用记事本打开 C:\Windows\System32\drivers\etc\hosts（只读查看，不要修改），找出文件里已有的静态映射记录。
验收清单：
  • 能说出 nslookup 返回的 Server 与 Address 各代表什么
  • 亲手做过 3 次以上域名解析
  • 能说出 hosts 文件属于静态映射还是动态映射
打不开 / 完不成：hosts 文件只查看不修改；除 ping 外不要执行其他网络命令。
实验二：浏览器里真跑 Linux 命令（零安装）
目标：不装系统、不装软件，在浏览器里进入真实 Linux 环境，练本课要求的目录与文件命令。
操作步骤：
  1. 打开 https://labex.io/zh/free-labs，选一个 Linux 入门类免费实验。
  2. 在实验终端里依次执行 pwd、ls -a、ls -l，观察三条命令的区别。
  3. 执行 cd / 后用 ls 查看根目录，再进 cd /etc、cd /home、cd /lib 各看一眼里面有什么。
  4. 执行 mkdir testdir、cd testdir、touch a.txt、ls -l，亲手建一个目录和一个文件。
  5. 执行 head -5 /etc/passwd，看用户信息存在哪个文件里；最后截图保存实验画面。
验收清单：
  • 用过 pwd / ls -a / ls -l / cd 四个命令
  • 亲手建过目录和文件
  • 能在根目录下指出 /etc、/var、/home、/lib 各放什么
打不开 / 完不成：免费账号每天最多启动 3 次实验，一次做完不要反复重启；Linux 命令严格区分大小写。
实验三：教师阿里云演示——在 Ubuntu 上安装 FTP 服务（教材实战项目）
目标：完整看一遍教材实战：连上云上的 Ubuntu 服务器、装 FTP 服务、传一个文件。
操作步骤：
  1. 教师机在阿里云控制台按量开通一台 Ubuntu 22.04 的 ECS（教师演示，学生记录步骤，不下单）。
  2. 用 SSH 工具（PuTTY 或云控制台自带远程连接）登录这台服务器。
  3. 演示安装与启动服务：sudo apt update → sudo apt install vsftpd → systemctl status vsftpd 查看服务是否运行。
  4. 在 Windows 上连接 FTP：资源管理器地址栏输入 ftp://服务器IP，上传并下载一个文件。
  5. 演示 systemctl stop vsftpd 后再连接会失败，体会「FTP 服务器必须先启动服务」；演示结束教师释放 ECS。
验收清单：
  • 记下 SSH 登录与 apt 安装的关键命令
  • 看到过 FTP 上传 / 下载成功的过程
  • 能说出 FTP 服务停掉后客户端会怎样
打不开 / 完不成：本实验由教师机演示、学生记录观察；云主机按量计费，演示结束立即释放。
