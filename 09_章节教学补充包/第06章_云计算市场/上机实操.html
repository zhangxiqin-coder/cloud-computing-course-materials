第 6 章 · 云计算市场
上机实操指导

机房环境：可上网、不可安装软件，全部实操基于网页 / 在线工具 / 系统自带命令

机房纪律：① 一律不安装任何软件，网站要求下载客户端时点「网页版」；② 涉及云厂商页面只看不买，绝不点付款；③ 下课前必须退出登录，浏览器问「是否保存密码」一律选「从不」。
实验一：云计算行业调研报告（浏览器 + 腾讯文档）
目标：按教材要求，独立完成一份结构完整的云计算行业调研报告，练「查资料 → 分析 → 成文」。
操作步骤：
  1. 确定一个调研题目（如「国内主流云厂商对比」「某行业的用云现状」），写在文档开头。
  2. 打开浏览器，查 2–3 个可靠来源（云厂商官网、行业报告、权威媒体），摘录关键数据。
  3. 按「背景 → 现状与数据 → 厂商 / 产品对比 → 分析与结论 → 建议」列提纲（对应教材的写作要求）。
  4. 用腾讯文档成文：要求内容全面、结构严谨、数据翔实，定量数据与定性分析结合。
  5. 给出自己的结论与建议，并注明资料来源。
验收清单：
  • 有明确的调研题目与提纲
  • 至少有 2 个可靠来源并标注
  • 有数据、有自己的分析和结论
  • 篇幅不少于 500 字
打不开 / 完不成：报告必须有「自己的分析和结论」，不能只堆资料；找不到数据时可用厂商官网公开信息。
实验二：主流云厂商「三层服务」对照表
目标：用一个表格把「厂商 × IaaS/PaaS/SaaS」理清楚，把服务模型和真实产品对应起来。
操作步骤：
  1. 在文档里建一个 4 列的表：厂商 / IaaS / PaaS / SaaS。
  2. 填入阿里云、腾讯云、华为云、百度智能云（或 AWS / Azure）各层的代表产品。
  3. 每格至少写 1 个产品名，并用一句话说明它是干什么的。
  4. 组内互相检查：有没有把同一层的产品放错位置。
验收清单：
  • 表格里有 4 家以上厂商
  • 每层至少 1 个产品并说明用途
  • 能与同学说清 IaaS / PaaS / SaaS 的分层依据
打不开 / 完不成：常见错误：把「对象存储」当成 PaaS；记住分层看的是「提供了什么」而不是「叫什么名字」。
