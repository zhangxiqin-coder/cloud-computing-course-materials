第 6 章 · 云计算市场
重难点与易错点

对应 教材 PPT：6.云计算市场.pptx｜课本 6.7 思考与练习 p.84–85

一、本章重点（必须掌握）

重点1
云计算带来的市场变革：IT 从「一次性买断硬件 / 软件许可」转向「按需租用服务」，企业由重资产投入变成按量付费的运营支出，这是云计算商业模式的根本变化。
重点2
3 种服务模型对应市场分层：IaaS 提供基础设施（EC2、ECS），PaaS 提供开发运行平台（Google App Engine、Salesforce Force.com），SaaS 直接提供软件（钉钉、Office 365）；大型厂商往往三层通吃。
重点3
国际主流厂商：AWS（2006 年推出，最早、份额第一）、Microsoft Azure（2008 年推出，原名 Windows Azure）、Google Cloud；国内代表：阿里云（2009 年成立，国内第一）、腾讯云、华为云、百度智能云。
重点4
百度云按 IaaS / PaaS / SaaS 三层展开：天算（IaaS）、天像·天工·天智（PaaS，含大数据与 AI）、天穹（SaaS），体现「云 + 大数据 + AI」三位一体战略。
重点5
云计算行业调研报告的基本要求：编写者要有独立策划，做到内容全面、结构严谨、数据翔实，定量与定性分析结合，成果应具有行业决策参考价值。

二、本章难点（讲慢一点、配比喻）

难点1
「市场变革」的实质：不是技术变了，而是交付与收费方式变了——从买断到订阅、从重资产到按量付费。要讲清「企业为什么愿意把机房交给云」。
难点2
厂商差异的辨析：阿里云（电商基因、IaaS 强）、腾讯云（社交 / 游戏 / 音视频）、华为云（政企、软硬一体）、百度智能云（AI / 大数据）——不是谁强谁弱，而是各自主场不同。

三、易错点（学生常错，务必提前点破）

易错1
把「云厂商」和「云服务模型」混为一谈——同一家厂商可以同时提供 IaaS / PaaS / SaaS（如阿里云既有 ECS 又有钉钉）。
易错2
以为「云计算就是把电脑搬到网上」——它的核心是资源池化 + 按需计费，不只是换了个位置。
易错3
把 Amazon S3（对象存储）误当成 PaaS——S3 属于基础设施层的存储服务，不是平台服务。
易错4
把 Altera、Xilinx 这类芯片 / FPGA 厂商误认为云服务商——它们不是 PaaS 提供商。
易错5
写调研报告只堆资料、没有自己的分析和结论——教材明确要求「独立策划、有决策参考价值」，不能只做搬运。
教师提示：建议把「易错点」单独投一屏，讲完知识点后立刻点破，比事后订正有效得多。
