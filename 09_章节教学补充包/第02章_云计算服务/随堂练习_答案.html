第 2 章 · 云计算服务
随堂练习答案与解析

题目来源：课本第 2 章 2.7 思考与练习（教材 p.32–33，按课本原样录入），共 15 题：单选 5 + 简答 10。简答题为参考答案；单选答案依据教材内容整理，请以官方答案为准。

配套《随堂练习.html》　｜　共 15 题

一、单项选择题

1. （　　）与 SaaS 不同，这种云计算服务模式把开发环境或者运行平台作为一种服务提供给用户。
答案：B
把开发 / 运行平台作为服务提供，即 PaaS（平台即服务）。
2. 亚马逊公司通过（　　），让用户可以通过 Web Service 方式租用计算机来运行自己的应用程序。
答案：C
Amazon EC2（弹性计算云）提供租用计算机的能力，属 IaaS；S3 是存储服务，HDFS / GFS 是分布式文件系统。
3. IaaS 即（　　）。
答案：C
IaaS = Infrastructure as a Service，基础设施即服务。
4. 亚马逊网络服务（Amazon Web Services，AWS）提供的云计算服务模式是（　　）。
答案：D
AWS 三类服务均有提供（如 EC2 属 IaaS、Elastic Beanstalk 属 PaaS、办公协作类应用属 SaaS）；若教材以 AWS 为 IaaS 典型案例，请以教材表述为准。
5. SaaS 即（　　）。
答案：A
SaaS = Software as a Service，软件即服务。

二、简答题

1. 简述 3 种云计算服务模式的主要区别。
答案：IaaS 提供的是计算基础设施的资源，SaaS 是提供软件资源，PaaS 是将软件研发平台作为一种服务提供给用户。
教材参考答案。
2. 简述 3 种云计算服务模式面向的用户群体。
答案：SaaS 主要面对的是普通的用户；PaaS 主要的用户是开发人员；IaaS 主要的用户是系统管理员。
教材参考答案。
3. 简述 3 种云计算服务模式的代表产品。
答案：SaaS：Salesforce Sales Cloud、Google Apps、Zimbra、Zoho、IBM Lotus Live 等。PaaS：Google App Engine、force.com、heroku、Windows Azure Platform 等。IaaS：Amazon EC2、Linode、Joyent、Rackspace、IBM Blue Cloud 和 Cisco UCS 等。
教材参考答案。
4. 谈谈你使用某云计算产品的感受，该产品属于哪一种服务模式？
答案：开放题，言之成理即可。示例：我常用百度网盘，它提供了大容量存储空间，可减轻本地存储压力、便于备份，属于面向普通用户的云服务。
教材给出开放式示例，鼓励学生结合真实体验作答。
5. 简述 3 种云计算服务模式以外的服务模式。
答案：BaaS 即后端即服务，应用架构由大量第三方云服务器和 API 组成，服务器端逻辑和状态由服务提供方管理。FaaS 即函数即服务，开发者只编写业务代码并部署到第三方无状态计算容器中，由事件触发执行。Serverless 则是把 BaaS 与 FaaS 组合在一起的应用架构。
教材参考答案。
6. 随着云计算技术的不断发展，IaaS 下一步将如何演变？
答案：开放题，要点参考：① 从「租机器」走向「租能力」，容器与 Serverless 让用户不再关心底层服务器；② 资源调度与运维走向智能化（自动伸缩、AIOps）；③ 算力类型更丰富（裸金属、GPU / FPGA 等，满足高性能与 AI 场景）；④ 与行业场景深度结合，出现面向特定行业的 IaaS 解决方案。
参考答案，言之成理即可。
7. PaaS 平台如何与人工智能、大数据等技术结合，为开发者提供更强大的工具和服务？
答案：开放题，要点参考：① 把 AI 能力封装成开箱即用的服务（语音识别、图像识别、机器学习平台），开发者调接口即可使用；② 提供托管的大数据组件（Hadoop、Spark、Flink），免去自建集群的麻烦；③ 打通数据仓库、数据湖与开发流水线（代码托管、CI/CD、监控、日志）；④ 通过低代码 / 无代码平台进一步降低开发门槛。开发者因此可以专注业务逻辑，而不是搭环境。
参考答案，言之成理即可。
8. SaaS 提供商怎么做才能吸引并留住用户？
答案：开放题，要点参考：① 产品好用、上手成本低（界面友好、支持移动端）；② 服务稳定可靠，数据安全有保障（SLA、备份、加密）；③ 定价灵活（免费试用、按需订阅、分档套餐）；④ 根据用户反馈持续迭代更新；⑤ 开放接口，与办公软件和第三方系统打通形成生态；⑥ 提供及时的技术支持与客户服务。
参考答案，言之成理即可。
9. IaaS、PaaS、SaaS 在安全性方面面临哪些挑战？
答案：开放题，要点参考：① IaaS：操作系统和应用由用户自己管理，配置错误（安全组、权限）风险高，还存在虚拟化层逃逸与资源隔离问题；② PaaS：平台与用户应用的责任边界模糊，平台漏洞会影响所有租户，多租户数据隔离难度大；③ SaaS：数据存放在厂商处，隐私与合规风险高，账号权限管理、数据泄露与误删是重点。共同挑战：多租户隔离、数据传输与存储安全、身份认证与访问控制。
参考答案，言之成理即可。
10. 云计算服务提供商要怎么做才能应对日益复杂的安全威胁？
答案：开放题，要点参考：① 技术上纵深防御：防火墙、入侵检测、数据加密（传输与存储）、DDoS 防护；② 管理上建立安全体系，通过等级保护、ISO 27001 等认证；③ 人员上加强安全培训与规范操作，避免误操作；④ 全量日志审计与安全态势感知，建立快速应急响应和灾备演练机制；⑤ 明确责任共担模型，向用户清晰划分双方的安全责任。
参考答案，言之成理即可。
