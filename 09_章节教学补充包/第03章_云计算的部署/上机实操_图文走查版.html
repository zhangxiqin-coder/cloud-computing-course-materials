第 3 章 · 云计算的部署
CloudSim 部署实战 · 图文走查版

适用场景：机房禁止安装软件（不能装 JDK / Eclipse）时，由老师按真实部署步骤现场演示，学生对照本页截图位与关键输出做记录，照样完成本章实战。无需真装环境。

师生分工：蓝条＝老师演示动作；黄条＝学生要看 / 要记的内容。每页留「截图位」和「学生记录栏」，下课前收作实验报告。
CloudSim 3.0.3 部署实战（走查版，与真装版步骤一致）
最终目标：看到控制台输出 Simulation completed! 与 CloudSimExample1 finished!，并理解 CloudSim 在模拟「数据中心 / 虚拟机 / 任务调度」。
▌ 第一步：安装并配置 JDK 8
老师演示：① 打开 JDK 8 安装包一路默认安装；② 此电脑→属性→高级系统设置→环境变量，新建 JAVA_HOME、编辑 CLASSPATH、给 Path 追加 %JAVA_HOME%\bin；③ 打开 cmd 输入 java -version 与 javac -version。
学生看：cmd 里弹出的版本号是不是 1.8.x。这就是「Java 环境就绪」的标志。
[ 截图位 ①：cmd 中 java -version / javac -version 的输出，确认显示 1.8.x ]
学生记录：JDK 版本号是 ________；CLASSPATH 最前面的特殊符号是 ________（提示：.;）
▌ 第二步：下载并解压 CloudSim 与依赖包
老师演示：① 打开 CloudSim 3.0.3 下载页（官网 / GitHub releases）展示压缩包；② 展示 Apache commons-math3-3.6.1.jar；③ 解压到 D:\CloudSim，展开目录让大家看 bin / docs / examples / jars。
学生看：CloudSim 是个「文件夹项目」不是单个 exe；commons-math3 是它运行必需的外部数学库，第三步要加进 Eclipse。
[ 截图位 ②：D:\CloudSim 解压后的目录结构，能看到 examples、jars 等文件夹 ]
学生记录：CloudSim 3.0.3 必须的外部数学库 jar 叫 ________（提示：commons-math3）
▌ 第三步：用 Eclipse 导入并运行示例
老师演示：① Eclipse → File → New → Java Project，项目名 CloudSim，取消 Use default location 指到解压目录；② Libraries 选项卡 Add External JARs 加入 commons-math3；③ 展开 examples → org.cloudbus.cloudsim.examples 打开 CloudSimExample1.java；④ 右键 Run As → Java Application。
学生看：控制台滚动的仿真日志，重点盯最后两行——出现 Simulation completed! 和 CloudSimExample1 finished! 即成功。
[ 截图位 ③：Eclipse 控制台最终输出，含 Simulation completed! 与 CloudSimExample1 finished! ]
学生记录：示例运行成功的关键标志是控制台出现 ________________ 和 ________________。
理解检查（口头回答即可）：CloudSim 在这个示例里其实没有真开虚拟机，它「模拟」了什么？——答：模拟了一个数据中心里，若干虚拟机如何分配、若干云任务（Cloudlet）如何被调度执行，并统计出每个任务的开始/结束时间。这就是「云计算部署与资源调度」的仿真。
走查验收清单（学生提交本页即过关）：
  • 三张截图位都已贴上对应画面（或手绘关键输出）
  • 三个「学生记录栏」已填写
  • 能口头说出 CloudSim 在模拟什么
若老师演示时也遇问题：① 版本不匹配——CloudSim 3.0.3 必须用 JDK 8，别用 JDK 11+；② 报找不到包——commons-math3 没加进 Libraries；③ 演示机也禁装时，改用网页版「四种部署方式选型」练习（见旧版上机实操）作为替代实战。
