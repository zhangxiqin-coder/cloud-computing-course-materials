第 3 章 · 云计算的部署
云部署模型实战（控制台参观 + 资源开通 + 模型归类）

对应教材实战项目「部署 CloudSim 平台」的替代方案。本班未学 Java，且机房统一走 Windows + 浏览器（实战全 Windows 完成、Linux 类改阿里云演示），故本章实战改为：在公有云控制台真实开通一个免费资源，并围绕「部署模型（公有 / 私有 / 混合 / 社区云）+ 责任共担」做归类与设计。零 Java、零安装，只需浏览器联网。

机房前提：本章实战只需 浏览器 + 联网，不装任何软件、不碰 Java。 账号与实名：阿里云 / 腾讯云控制台需注册账号，部分资源开通要做实名认证（绑手机号）。建议教师用统一演示账号现场操作，学生观察跟练；学有余力且已实名的学生可自行注册「免费试用」资源。 安全红线：只用 免费额度 / 按量试用，不下单、不绑卡、不付费；弹「保存密码」一律选「从不」；下课必须退出登录。
云部署模型实战（控制台参观 + 资源开通 + 模型归类）
目标：① 在公有云控制台真实开通一个免费资源（OSS 存储桶 / 或试用 ECS），体验「公有云」自助开通；② 识别它属于哪种部署模型；③ 用同一场景对比 公有云 / 私有云 / 混合云 三种部署方式，并填「责任共担」分工表。
▌ 第一步：控制台参观 + 登录（教师演示为主）
  1. 打开 阿里云控制台 https://home.console.aliyun.com（或腾讯云 https://console.cloud.tencent.com），教师用演示账号登录；学生观察首页的产品分类（计算 / 存储 / 网络 / 数据库…）。
  2. 认识「地域与可用区」「产品导航」：云资源分布在哪、用户如何自助开通——这正是公有云「按需自助服务」特征的体现。
  3. 学生若自行操作：先用手机号注册并完成实名认证（约 2 分钟），再进入控制台。
预期：能说清「控制台 = 自助管理云资源的网页后台」，并理解它对应的就是公有云的「按需自助服务」特征。
▌ 第二步：开通一个免费资源——对象存储 OSS 存储桶（最稳、零费用）
  1. 控制台 → 产品与服务 → 对象存储 OSS → 创建 Bucket。
  2. 填 Bucket 名称（全局唯一，如 class-photo-你的学号）、地域（选离学校近的）、读写权限先选「私有」。
  3. 进入 Bucket → 上传一个文件（如一张班级照片），上传成功后截图：能看到文件 URL 与存储类型。
  4. 把读写权限改成「公共读」再截图对比，理解「权限配置」属于用户责任。
预期：成功创建并上传，控制台显示文件管理与 URL——这就是你亲手开通的「公有云存储资源」。
▌ 备选第二步：试用一台云服务器 ECS（想体验「计算」资源时）
  1. 控制台 → 云服务器 ECS → 实例 → 创建实例，选「免费试用 / 按量付费」、最小规格（1 核 1G）、公共镜像（如 Alibaba Cloud Linux）。
  2. 不买数据盘、不购带宽包，确认金额为 0 或按量极低再创建；创建后可在「远程连接」里用 Workbench 登录看一眼命令行。
  3. 切记：试用完在教师指导下释放实例，避免产生费用。
▌ 第三步：责任共担识别（本章核心）

在控制台里找这些项，讨论「归云厂商」还是「归用户」，填分工表：

项目负责方
物理机房 / 网络设备云厂商
虚拟化层 / 云产品自身漏洞修复云厂商
操作系统补丁 / 应用安全用户
账号密码 / 访问密钥(AK) 保管用户
数据加密 / 备份策略用户（可借助厂商工具）
记口诀——「云厂商管下层（基础设施），用户管上层（数据与应用）」，这就是责任共担模型。
▌ 第四步：部署模型归类与设计（本章重点）

场景：给「班级相册 / 选课系统」分别用三种方式部署，填对比表：

部署方式怎么部署成本安全可控适用
公有云全部用阿里云 OSS + ECS低（按量）中（依赖厂商）快速上线、弹性
私有云学校自己机房服务器高（一次性）高数据敏感、合规
混合云公开照片放公有云 + 学生信息放校内私有云中高兼顾弹性与隐私

归类练习（口头 / 纸条）：判断以下属于哪种部署模型——

  • 微信小程序云开发 → 公有云
  • 学校财务系统内网服务器 → 私有云
  • 政务系统「敏感数据校内 + 对外服务公有云」 → 混合云
  • 行业联盟共享平台 → 社区云
验收清单：
  • 成功在控制台开通一个免费资源（OSS 桶 或 试用 ECS）并截图
  • 能说出它属于「公有云」部署
  • 能列举 2 条以上「归用户负责」的责任共担项
  • 能区分 公有云 / 私有云 / 混合云 并各举一例
常见问题与救场：
  • 实名认证卡住：教师统一演示即可，学生不必人人实名；或改用「仅参观控制台、不创建资源」的图文走查版。
  • 怕产生费用：只用免费额度 / 按量试用，创建前看清金额为 0；下课统一释放实例、退出登录。
  • 地域选错：删除重建即可；OSS / ECS 创建后地域一般不可改，注意选近的。
  • 机房限制账号注册：改用独立文件 上机实操_图文走查版.html——老师按步骤演示，学生把每一步截图和关键输出抄进实验报告，照样完成本章实战。
进阶（学有余力）：把「班级相册」设计成混合云：敏感原图放私有云（校内服务器）、对外展示的缩略图放公有云 OSS，画一张拓扑并用箭头标出数据流向——正好呼应本章「云计算的部署」主题。
