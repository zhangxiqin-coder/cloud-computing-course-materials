第 3 章 · 云计算的部署
CloudSim 仿真平台部署实战

对应教材实战项目：部署 CloudSim 平台。CloudSim 是用 Java 编写的云计算仿真平台，可在本机模拟数据中心、虚拟机与任务的调度过程，是理解「云计算部署」最直观的动手实验。

机房前提：本章实战需要安装软件——JDK 8 与 Eclipse。请机房课前放开这两项的安装权限。若机房仍禁止安装，请改用下方「图文走查版」：老师按步骤现场演示，学生对照截图跟流程、记录关键输出，不真装环境。
CloudSim 3.0.3 部署实战（教材默认版本，免 Maven，最稳）
目标：在本机成功部署 CloudSim 3.0.3，并运行自带示例 CloudSimExample1，控制台出现 Simulation completed! 即算过关。
▌ 第一步：安装并配置 JDK 8
  1. 下载 JDK 8（建议 AdoptOpenJDK / Oracle JDK 8），一路默认安装到 C:\Program Files\Java\jdk1.8.0_xx。
  2. 配置环境变量（此电脑 → 属性 → 高级系统设置 → 环境变量）：
    • JAVA_HOME = JDK 安装目录（如 C:\Program Files\Java\jdk1.8.0_221）
    • CLASSPATH = .;%JAVA_HOME%\lib;%JAVA_HOME%\lib\tools.jar（注意最前面的 .;）
    • Path 追加 %JAVA_HOME%\bin;%JAVA_HOME%\jre\bin
  3. 验证：打开 cmd 输入 java -version 与 javac -version，均显示 1.8.x 即成功。
预期：两条命令都能正常输出版本号，说明 JDK 与编译环境就绪。
▌ 第二步：下载并解压 CloudSim 与依赖包
  1. 下载 CloudSim 3.0.3（官网 cloudsim.org 或 GitHub releases），得到 cloudsim-3.0.3.zip。
  2. 额外下载 Apache commons-math3（CloudSim 3.x 必需的数学库）的 jar 包，如 commons-math3-3.6.1.jar。
  3. 全部解压到同一文件夹（如 D:\CloudSim），确保能看到 bin / docs / examples / jars / sources 等目录。
预期：解压目录结构完整；commons-math3 的 jar 单独放在手边，第三步要加入构建路径。
▌ 第三步：用 Eclipse 导入并运行示例
  1. 打开 Eclipse → File → New → Java Project，项目名填 CloudSim；取消勾选 Use default location，Browse 指向刚解压的 CloudSim 目录，Next。
  2. 切到 Libraries 选项卡：若列表中没有 commons-math3-3.x.jar，点 Add External JARs 把它加进来，Finish。
  3. 在 Project Explorer 展开 examples → org.cloudbus.cloudsim.examples，双击打开 CloudSimExample1.java。
  4. 右键 Run As → Java Application（或按 Ctrl+F11）。
预期：控制台滚动输出仿真信息，最后出现 Simulation completed! 与 CloudSimExample1 finished!，并列出各云任务（Cloudlet）的执行结果——部署成功。
验收清单：
  • java -version 与 javac -version 均显示 1.8.x
  • CloudSim 3.0.3 解压完整，commons-math3 jar 已加入构建路径（Libraries）
  • 成功运行 CloudSimExample1，控制台出现 Simulation completed!
  • 能说出 CloudSim 在模拟什么（数据中心 / 虚拟机 / 任务调度的资源分配）
常见问题与救场：
  • JDK 版本不匹配：CloudSim 3.0.3 必须用 JDK 8；JDK 11+ 容易报类找不到。想用 CloudSim 4.0 才需 Maven，新手先别碰。
  • Eclipse 报找不到包：九成是 commons-math3 没加进 Libraries，回去 Add External JARs 补上。
  • 机房禁装：改用独立文件 上机实操_图文走查版.html——老师按上面三步演示，学生把每一步的截图和关键输出抄进实验报告，照样算完成本章实战。
进阶（学有余力）：把 CloudSimExample1 里的虚拟机数量、任务长度改一改再跑，观察控制台输出的执行时间变化——这就是「部署方式 / 资源配置」对性能的影响的直观体现，正好呼应本章「云计算的部署」主题。
