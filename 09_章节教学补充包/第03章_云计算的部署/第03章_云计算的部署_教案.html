第3章 云计算的部署 · 教案

教材：《云计算基础技术与应用(第2版)(微课版)》ISBN 978-7-115-66457-0

一、教学目的
  1. 理解云计算的部署含义：云端由数以万计的计算机组成，资源可随时随地进行扩展和压缩，最大程度减少硬件浪费、降低成本。
  2. 掌握四种部署模型：公有云、社区云、私有云、混合云的概念、特点与适用场景，以及各自的核心属性。
  3. 能比较四种部署方式的联系与区别（安全性、规模经济、成本、相互补充长期共存），并初步判断不同企业适合哪种云。
  4. 第 3 课时上机做「云控制台部署模型实操」（在公有云控制台开通免费资源 + 部署模型归类 + 责任共担，教材原 CloudSim 实战的替代方案，因本班未学 Java 且机房走 Windows+浏览器），第 4 课时独立完成本章随堂练习。
二、重点、难点及处理方法

教学重点：

  1. 四种部署方式：公有云、社区云、私有云、混合云。
  2. 公有云（厂商建好、谁都能租、便宜随开随用，但数据在别人家；分布式是其基石）与私有云（一家自建自用、安全可控，但成本自担；虚拟化是其基石）的核心区别。
  3. 混合云：公私搭配，敏感数据走私有、一般业务走公有，兼顾安全与成本。

教学难点：

  1. 社区云与公有云的区别：社区云面向特定行业 / 目标相似的组织，由成员共同承担成本。
  2. 混合云不是「两个云随便连」，涉及数据流动、网络打通和统一运维，复杂度明显上升。

处理方法：

  • 用「租房子（公有云）/ 自建房（私有云）/ 小区共享设施（社区云）/ 主房+租用仓库（混合云）」比喻，把四种部署模型一次讲清。
  • 用一张「四种部署模型对比表」投屏（谁建设、谁使用、数据在哪、适合谁），逐行请学生口头补全，重点纠正社区云 vs 公有云、混合云「能协同≠各买一套」的混淆。
  • 把 5 条易错点单独投一屏提前点破：私有云不一定更安全（看管理配置）、混合云关键在协同、社区云≠公有云、小公司未必扛得住私有云、混合云还有网络专线与运维成本。

五、作业

1、 完成随堂练习中当场未做完的题目（课本第 3 章「思考与练习」原题，见补充包「随堂练习.html」）。

3、 整理第 3 课时云控制台实操的 1 张截图或 1 句操作记录（如「在阿里云开通了一个 OSS 存储桶，识别为公有云」）。

六、教学过程
1
讲课：部署方式概述 + 公有云 + 社区云
教材原版 PPT 第3章 4–20 页 ｜ 90 分钟
环节教学活动
引入教师：提问「你用的网盘、视频网站，服务器是你家的吗？——这就是『部署』要回答的问题：云建在哪、给谁用」。引出部署模型。
视频播放：课前缓存的「公有云 私有云 混合云 区别 动画讲解」（6–10 分钟）。播前问「视频里房子比喻了什么」，播后请 2 人回答。
讲解教师：讲部署概述——云端由数以万计计算机构成，资源可随时扩展压缩，按需求分配，像超级计算机却成本低。讲公有云：也称外部云，厂商建在数据中心、向公众提供，核心属性是共享资源服务，理论上任何人授权即可接入；计算模型分接入 / 平台 / 管理三部分；典型有天翼云、AWS、阿里云等；最大制约是安全性（数据不在自己数据中心）。分布式是公有云的基石。
讲解教师：讲社区云：一定地域 / 特定小组内、目标相似成员共享一套基础设施、成本共担；特点为区域型和行业性、有限特色应用、资源高效共享、成员高度参与。
互动师生：口头接龙，每人说一个公有云产品（网盘、腾讯视频、阿里云等），教师归类到黑板；再请 1 人试着用一句话区分「社区云」和「公有云」。
收口教师：小结本课要点；预告下节课讲私有云与混合云，并上机做云控制台部署模型实操。
2
讲课：私有云 + 混合云 + 四种部署方式的联系和区别
教材原版 PPT 第3章 21–41 页 ｜ 90 分钟
环节教学活动
引入教师：提问「如果是一家银行，敢把客户数据放别人家的公有云吗？」引出私有云与混合云。
讲解教师：讲私有云：也称内部云，为用户单独构建，核心属性是专有资源，数据安全和 SLA 自己掌控；优势是数据安全、服务质量、充分利用现有资源；缺点是投资大、规模经济受限。虚拟化是私有云的基石。
讲解教师：讲混合云：两种及以上云的混合体（如公有 + 私有），相互独立又内部结合；核心用法是敏感 / 核心程序放私有云，非核心放公有云；优势是更完美（安全 + 算力）、可扩展、更节省。点明混合云不是「各买一套」，关键在两者能协同。
讲解教师：讲四种部署方式的联系和区别：① 私有云安全性好；② 公有云更符合规模经济效益；③ 社区云降低运营开发成本；④ 混合云集成双重优势；⑤ 四者长期共存、优势互补，不会谁取代谁。
互动师生：教师把「四种部署模型对比表」画在黑板（谁建设 / 谁使用 / 数据在哪 / 适合谁），逐行请学生口头补全；同步点破 5 条易错点（私有云不一定更安全、混合云关键在协同、社区云 ≠ 公有云、小公司未必扛得住私有云、混合云还有专线运维成本）。
收口教师：一句话总结四者关系；点明下节课上机做云控制台部署模型实操，把部署从名词变成操作。
3
实战：云控制台部署模型实操
教材原版 PPT 第3章（云部署模型）｜ 衔接补充包「上机实操.html」（含「图文走查版」）｜ 90 分钟
环节教学活动
布置教师：说明实战目标——在公有云控制台（阿里云 / 腾讯云）真实开通一个免费资源（对象存储 OSS 存储桶或试用 ECS），识别它属于「公有云」部署，并围绕责任共担与三种部署模型做归类。强调安全红线：只用免费额度 / 按量试用，不下单、不绑卡、不付费，下课退出登录。实名 / 注册受限时教师用演示账号操作。
实操电脑学生（分步完成，详细见补充包「上机实操.html」+「上机实操_图文走查版.html」）：
① 登录控制台（教师演示账号或学生已实名账号），观察产品分类与地域选择器；
② 开通对象存储 OSS 存储桶：命名（全局唯一）→ 选地域 → 读写权限选「私有」→ 上传一张班级照片；
③ 把权限改为「公共读」再对比，理解权限配置是用户责权；
④ 识别该资源属于「公有云」，在控制台找责任共担项，讨论厂商 vs 用户；
⑤ 用「班级相册 / 选课系统」场景对比公有云 / 私有云 / 混合云，填对比表并做归类练习。
（实名 / 注册受限，教师用「图文走查版」投影演示，学生观摩记录）
巡堂教师：走动答疑，收集典型问题（实名认证卡住、地域选错、担心产生费用），投屏演示 1–2 个常见卡点，重申安全红线。
收口教师：请 1–2 组展示开通成功的资源（OSS 桶 / 试用 ECS），点出「你刚亲手开通的就是一个公有云资源，四种部署模型里的『公有云』本质就是这么一套自助开通、按需使用的服务」。要求每人留 1 张截图或 1 句操作记录进笔记。
4
随堂练习 + 讲解练习情况
用补充包「随堂练习.html」（课本原题）｜ 90 分钟
环节教学活动
练习学生：完成补充包「随堂练习.html」中的课本第 3 章「思考与练习」原题（教师投影题目或印发，学生作答于作业本）。教师计时，约 35–40 分钟独立完成。
收看教师：巡堂收看完成情况，标记错误率高的题目（通常集中在四种模型区分、社区云 vs 公有云、混合云协同、易错点相关题）。
讲解教师：挑选错误率最高的 6–8 题重点讲解，公布答案要点（参考补充包「随堂练习_答案.html」），让学生对照订正。
收口教师：回扣本章易错点做总结；未做完的题作为作业补完。
七、课后小结
人工智能241班：应到 38 人，实到 38 人（全勤）。课时 1–2 四种部署模型达成度较好，租房子 / 自建房比喻学生接受快；「社区云 vs 公有云」「混合云协同」仍是难点，需下次补对比练习。课时 3 云控制台部署模型实操多数完成 OSS 存储桶开通并识别为公有云、填好责任共担表，个别实名 / 注册受限改用教师机「图文走查版」演示。课时 4 随堂练习四种模型区分类题正确率约 80%，混合云协同类题失分较多，已现场重讲。下次：四种部署模型对比表提前发，课堂多留填表与实操时间。
