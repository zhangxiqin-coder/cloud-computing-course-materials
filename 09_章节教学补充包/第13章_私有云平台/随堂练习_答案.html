随堂练习答案与解析

一、简答题

1. 比较私有云和公有云的区别。
答案：公有云和私有云的最大区别在于是否对外开放，公有云是对外开放的，而私有云则是只针对企业内部开放的。使用公有云不需要专有的客户端，而私有云通常是需要专用的软件。
主线：最大区别=是否对外开放；公有云免专用客户端，私有云常需专用软件。
2. OpenStack 有哪些组件?
答案：OpenStack 的组件有：Horizon、Nova、Neutron、Swift、Cinder、Glance、Keystone、Ceilometer、Heat。
九大组件按类记：界面(Horizon)/计算(Nova)/网络(Neutron)/对象存储(Swift)/块存储(Cinder)/镜像(Glance)/认证(Keystone)/计量(Ceilometer)/编排(Heat)。
3. Eucalyptus 的主要特点是什么?
答案：Eucalyptus 主要特点包括与 EC2 和 S3 的接口兼容性、支持运行在 Xen hypervisor 或 KVM 之上的 VM 的运行、用来进行系统管理和用户结算的云管理工具、能够将多个分别具有各自私有的内部网络地址的集群配置到一个云内。
四特点：兼容 EC2/S3 接口 / 支持 Xen·KVM / 云管理工具 / 多集群纳入一云。
4. OpenStack 的Nova组件的主要功能有哪些?
答案：Nova 组件提供虚拟机的创建、运行、迁移、快照等围绕虚拟机的服务，并提供 API 与控制节点对接、由控制节点下发任务。
主线：虚拟机生命周期(创建/运行/迁移/快照) + API 对接控制节点。
5. 谈谈你对开源云平台的看法。
答案：开源云平台（如 OpenStack）的优势：免费、代码透明、生态活跃、不被厂商锁定、可深度定制，适合有技术实力的企业自建私有云。不足：组件多、部署运维复杂、需要专业团队，纯社区版缺乏商业支持。选型建议：技术储备强的企业可用开源自建；求稳的企业可选用商业发行版或公有云。总体看，开源是云计算的重要趋势，但与商业方案互补而非替代。
教材答案标「略」，以下为依据本章 PPT 与正文整理：优势(免费/透明/生态/可定制) vs 不足(复杂/需团队)，结论互补。
6. OpenStack 是怎样发展起来的?
答案：OpenStack 由 NASA（美国国家航空航天局）与 Rackspace 于 2010 年联合发起，最初整合了 NASA 的 Nebula 计算部分与 Rackspace 的存储部分（Swift），以 Apache 2.0 开源协议发布。之后迅速形成庞大社区，吸纳众多厂商（红帽、华为、英特尔等）贡献，逐步从计算+存储扩展到网络(Neutron)、块存储(Cinder)、镜像(Glance)、认证(Keystone)、界面(Horizon)、编排(Heat)、计量(Ceilometer)等完整体系，成为最主流的开源云计算管理平台之一。
教材答案标「略」，以下为依据本章 PPT 与正文整理：2010 NASA+Rackspace 开源 → 社区壮大 → 组件体系完善。
7. OpenStack 的网络由哪个组件提供?
答案：OpenStack 的网络由 Neutron 组件提供，Neutron 负责管理私有网络与公有网络的通信，以及管理虚拟机网络之间通信/拓扑、管理虚拟机之上的防火墙等等。
网络=Neutron，职责：私有/公有网络互通、VM 网络拓扑、防火墙。
8. OpenStack 的存储是怎样实现的?
答案：OpenStack 通过 Swift 和 Cinder 提供存储服务。其中 Cinder 是块存储服务，提供相应的块存储，简单来说就是虚拟出一块磁盘，可以挂载到相应的虚拟机之上，不受文件系统的影响，对虚拟机来说像加了一块硬盘，可完成挂载、卸载、格式化、转换文件系统等操作，多用于虚拟机空间不足时的扩容。Swift 是对象存储服务，提供相应的独享存储，简单来说就是虚拟出一块磁盘空间，可以存放文件，也仅仅只能存放文件，不能格式化、转换文件系统，多用于云磁盘/文件。
Swift=对象存储(存文件、不能格式化)；Cinder=块存储(像硬盘、可挂载格式化)，常扩容量。
9. OpenStack的身份认证是怎样实现的?
答案：OpenStack 的身份认证通过 Keystone 实现，Keystone 为所有的 OpenStack 组件提供认证和访问策略服务，它依赖自身的 REST（基于 Identity API）系统进行工作，主要对（但不限于）Swift、Glance、Nova 等进行认证与授权。
认证=Keystone，基于 REST Identity API，对各组件认证与授权。
10. OpenStack 提供了一个用户接口，是由哪个服务提供的?
答案：是由 Horizon 提供的。
Web 管理界面=Horizon，是外界管理云的唯一通道。
11. 什么是私有云？它适合什么样的企业？
答案：私有云是企业自行（或委托服务商）配置软硬件基础设施、搭建云服务平台、仅供内部人员使用的云。它适合：① 对数据安全与合规要求高的行业（金融、政企、医疗）；② 已有大量异构 IT 资产、需要统一纳管的大企业；③ 业务稳定、对可控性/定制性要求高的场景。相对公有云，它的优势是隔离、可控，代价是自建成本高、运维重。
主线：企业自建+仅供内部 → 适合高安全/大企业/强可控场景。
12. 简述 OpenStack 的发展背景与意义。
答案：OpenStack 诞生于 2010 年，由 NASA 与 Rackspace 联合开源发布，目的是用开放标准打破云计算平台的厂商锁定，让企业能用一套开源软件自建类 AWS 的云。它的意义在于：把「云平台」从少数巨头专有，变成社区共建、代码透明的公共资产，推动了私有云与混合云的普及，也成为众多商业云发行版的基础。
背景：2010 NASA+Rackspace 开源；意义：打破锁定、推动私有云普及。
13. Glance 镜像服务的作用是什么？它与 Swift/Cinder 有何不同？
答案：Glance 是 OpenStack 的镜像服务，负责虚拟机镜像的发现、注册与检索（glance-api 接收 REST 请求，glance-registry 与数据库交互，image store 是存储接口层）。它与 Swift/Cinder 的区别：Swift 是对象存储（存文件）、Cinder 是块存储（像硬盘），二者存的是「用户数据」；Glance 存的是「虚拟机模板（镜像）」，用于创建虚拟机时提供系统盘模板。
Glance=镜像模板；Swift=对象数据；Cinder=块设备，三者存储对象不同。
14. 什么是 Heat 和 Ceilometer？它们分别解决什么问题？
答案：Heat 是 OpenStack 的编排服务，用模板（如 HOT）把计算、网络、存储等资源按依赖关系自动编排部署，解决「多资源一次性、可重复创建」的问题。Ceilometer 是计量/监控服务，采集各组件的资源使用与事件数据，为计费、告警、容量规划提供依据，解决「云资源用量可见、可计量」的问题。
Heat=编排部署；Ceilometer=计量监控，各解决一类运维问题。
15. 如果你要为企业设计一套私有云方案，会考虑哪些要点？
答案：① 明确需求与规模：业务类型、虚拟机数量、数据量与合规要求；② 选型：自研 OpenStack 还是商业发行版/超融合，技术储备决定是否自建；③ 资源池设计：计算（Nova+KVM）、网络（Neutron Overlay）、存储（Cinder/Swift 配比）；④ 高可用与容灾：控制节点冗余、存储多副本；⑤ 安全：Keystone 统一认证、安全组/防火墙、租户隔离；⑥ 运维：监控(Ceilometer)、编排(Heat)、备份与扩容预案；⑦ 成本与团队：TCO 与运维人力评估。
从需求/选型/资源池/高可用/安全/运维/成本七个维度谈，结合 OpenStack 组件。
