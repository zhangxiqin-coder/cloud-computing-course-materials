第 13 章 · 私有云平台
重难点与易错点

对应 教材 PPT：13.私有云平台.pptx（40 页）｜ 课本 13 思考与练习 p.208

一、本章重点（必须掌握）

重点1
私有云概念：企业自行（或委托服务商）配置软硬件、搭建云服务平台、仅供内部使用的云；与公有云最大区别是「是否对外开放」——私有云只对企业内部开放、通常需专用软件。
重点2
OpenStack 定位：开源的云计算管理平台项目，既是一个社区、也是一个项目/开源软件；核心组件含 Nova（计算）、Neutron（网络）、Swift（对象存储）、Cinder（块存储）、Glance（镜像）、Keystone（认证）、Horizon（界面）、Heat（编排）、Ceilometer（计量）。
重点3
计算 Nova：弹性控制器，提供虚拟机创建/运行/迁移/快照等生命周期管理，通过 libvirt API 与宿主机交互；采用异步通信（AMQP 消息队列），用户动作不被长时间阻塞。
重点4
网络与存储：Neutron 提供虚拟网络（租户自建虚拟网络/子网/路由器）；Swift 提供分布式对象存储，Cinder 提供块存储（可挂载、格式化，像加硬盘）。
重点5
认证与界面：Keystone 为所有组件提供认证与访问策略（基于 Identity API）；Horizon 是 Web 管理界面（外界管理云的唯一通道）；Glance 负责镜像发现/注册/检索。

二、本章难点（讲慢一点、配比喻）

难点1
OpenStack 组件多、关系杂：Nova/Neutron/Swift/Cinder/Glance/Keystone/Horizon 各自职责要成组记，尤其是「计算/网络/存储/镜像/认证/界面」六类不能张冠李戴。
难点2
Swift（对象存储）与 Cinder（块存储）易混：Swift 只能存文件、不能格式化；Cinder 像加硬盘、可挂载格式化，常用于扩容。
难点3
OpenStack 的「开源」与「商业发行版」区别：社区版免费但需自运维，企业多用发行版（如华为、红帽）获得支持，课堂要讲清「开源≠零成本运维」。

三、易错点（学生常错，务必提前点破）

易错1
以为私有云就是「自己买几台服务器」——私有云是「云化的」管理平台（自助/弹性/池化），不是简单堆硬件。
易错2
混淆 OpenStack 的 Swift 和 Cinder——Swift 对象存储（存文件、不能格式化），Cinder 块存储（像硬盘、可挂载格式化）。
易错3
以为 Horizon 是 OpenStack 的核心——它只是 Web 管理界面（入口），真正的控制在 Nova/Neutron 等组件。
易错4
把 Keystone 当成「数据库」——它是认证/授权服务（基于 REST Identity API），glance-registry 才与 MySQL 交互。
易错5
以为 OpenStack 自带虚拟能力——Nova 本身不提供虚拟化，它通过 libvirt 调用底层 KVM/Xen 等 Hypervisor。
教师提示：建议把「易错点」单独投一屏，讲完知识点后立刻点破，比事后订正有效得多。
