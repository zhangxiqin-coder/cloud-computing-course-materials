第 13 章 · 私有云平台
上机实操指导

机房环境：可上网、不可安装软件，全部实操基于网页 / 在线工具 / 系统自带命令

机房纪律：① 一律不安装任何软件，网站要求下载客户端时点「网页版」；② 涉及云厂商页面只看不买，绝不点付款；③ 下课前必须退出登录，浏览器问「是否保存密码」一律选「从不」。
实验一：OpenStack 组件架构图标注（浏览器看官网架构图）
目标：把最易混的九大组件用一张标注图固定下来，分清「计算/网络/存储/镜像/认证/界面」。
操作步骤：
  1. 打开 OpenStack 官网 架构介绍页，找到组件架构图。
  2. 在纸上重画简化架构图，标注 Nova/Neutron/Swift/Cinder/Glance/Keystone/Horizon 六个核心组件，每个旁边写一句职责。
  3. 用不同颜色区分：计算类、存储类、网络类、管理类。
  4. 互相口述：用户通过什么入口管理云？认证由谁做？虚拟机由谁管？
验收清单：
  • 重画并标注架构图
  • 六大组件职责写全
  • 能口述入口/认证/计算归属
打不开 / 完不成：只看官网图，不下载安装 OpenStack。
实验二：私有云 vs 公有云 对比调研（搜索引擎查企业案例）
目标：通过真实案例理解两类云的取舍，巩固本章核心区别。
操作步骤：
  1. 用搜索引擎查「企业私有云 案例」或「金融 私有云」，找 2–3 个真实落地案例。
  2. 填对比表：云类型 / 选用企业 / 选用原因 / 典型收益（各 3 行）。
  3. 讨论：为什么银行/政务多用私有云，而初创公司多用公有云？
验收清单：
  • 查到 2–3 个真实案例
  • 对比表填完
  • 能说出两类云选型逻辑
打不开 / 完不成：只用搜索引擎公开信息，不点击不明下载。
实验三：撰写一份「开源云平台调研报告」（Word / 腾讯文档）
目标：综合运用本章知识，产出一份可提交的调研报告，对应教材实战项目。
操作步骤：
  1. 新建一份文档，标题「开源云平台调研报告」。
  2. 第一部分：OpenStack 简介（定位、九大组件、发展背景）。
  3. 第二部分：对比 OpenStack 与 Eucalyptus / CloudStack（组件、特点、适用场景）。
  4. 第三部分：结论——什么企业适合用开源私有云，注意事项是什么。
  5. 排版后保存，作为本章实战作业提交。
验收清单：
  • 报告含三部分结构
  • 对比了至少 2 个开源平台
  • 给出明确选型结论
打不开 / 完不成：报告用学校允许的文档工具完成，注意引用来源。
