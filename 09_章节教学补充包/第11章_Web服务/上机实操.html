上机实操指导

机房环境：可上网、不可安装软件，全部实操基于网页 / 在线工具 / 系统自带命令

机房纪律：① 一律不安装任何软件，网站要求下载客户端时点「网页版」；② 涉及云厂商页面只看不买，绝不点付款；③ 下课前必须退出登录，浏览器问「是否保存密码」一律选「从不」。
实验一：用 XAMPP 在 Windows 本机搭一个网站（对应教材实战 PHP+MySQL+Apache）
目标：在本机 Windows 上启动 Web 服务器与数据库，亲手访问一个动态页面，理解 Apache + PHP + MySQL 这套经典 Web 技术栈。
操作步骤：
  1. 打开 XAMPP 控制面板，依次点击 Apache 与 MySQL 的 Start，等状态变绿。
  2. 浏览器访问 http://localhost（或 http://127.0.0.1），看到 XAMPP 欢迎页即成功。
  3. 进入 XAMPP 安装目录的 htdocs 文件夹，新建 hello.php，写入一段 PHP 代码输出「Hello Cloud」。
  4. 浏览器访问 http://localhost/hello.php，看到输出；再访问 http://localhost/phpmyadmin 看 MySQL 管理界面。
  5. 讨论：你在浏览器地址栏敲的 localhost 是怎么被 Apache 接住并返回页面的？
验收清单：
  • Apache 与 MySQL 都启动过
  • 访问过 localhost 欢迎页
  • 自己写过并运行过一个 .php 文件
打不开 / 完不成：XAMPP 默认端口 80，若被占用先关掉占用程序；实验结束点 Stop 释放端口。
实验二：浏览器开发者工具拆解一次 HTTP 请求与 URL 组成
目标：用浏览器自带的开发者工具，亲眼看到一次网页请求背后发生了什么，并拆开一个完整 URL。
操作步骤：
  1. 按 F12 打开开发者工具，切到 Network（网络）面板。
  2. 在地址栏访问一个网站（如学校官网），观察 Network 里出现的请求：请求行、状态码、响应头。
  3. 点开其中一条请求，看 Request URL，把它按「协议 / 主机 / 端口 / 路径 / 查询」拆开写在纸上。
  4. 把该网站地址改成 https:// 再访问一次，对比 HTTP 与 HTTPS 在 Network 里的差异（是否有证书、是否加密）。
  5. 截图保存一次完整请求的头部信息。
验收清单：
  • 用过 F12 的 Network 面板
  • 能拆出一个 URL 的各组成部分
  • 能说出 HTTP 与 HTTPS 在请求上的区别
打不开 / 完不成：只看请求与响应头，不下载、不安装任何插件。
实验三：三层架构与 SLA/QoS 对照小练习
目标：把抽象的三层架构和容易混的 SLA/QoS 用一张对照表固定下来。
操作步骤：
  1. 在纸上画三层架构图，标注 UI / BLL / DAL 三层，并在每层旁写一句职责。
  2. 对照教材，举一个「用户登录」例子，分别说出三层各自做了什么。
  3. 再画一张 SLA 与 QoS 对照表：左列写 SLA（协议/承诺），右列写 QoS（技术机制），各写 3 条。
  4. 两人一组互相口述：为什么说「SLA 是承诺、QoS 是实现承诺的手段」？
验收清单：
  • 画出三层架构并标注职责
  • 画出 SLA/QoS 对照表
  • 能口述二者关系
打不开 / 完不成：本实验为纸上/讨论练习，不操作电脑。
