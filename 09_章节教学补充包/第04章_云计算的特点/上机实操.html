第 4 章 · 云计算的特点
安装虚拟机软件 VMware · 体验虚拟化实战

机房环境：可上网。本章实战项目（教材原版 PPT 第 4 章 25–27 页）为「安装虚拟机软件 VMware，了解虚拟化特点」。本课由教师机安装演示 + 学生机安装实操，亲手把一台物理机「变」出多台电脑，直观体会资源虚拟化、资源池化、按需分配与快速弹性。

安装来源：VMware 安装包由教师从局域网共享 / U 盘统一分发（建议 VMware Workstation Player 免费版，或机房已有的 Workstation Pro），不要求学生当场外网下载，避免机房带宽压力。机房若已预装 VMware，则直接进入「新建虚拟机」步骤。
实战项目：安装虚拟机软件 VMware，了解虚拟化特点（教材原实战）
目标：① 完成 VMware 的安装；② 新建 1–2 台虚拟机并启动，观察「一台物理机切出多台虚拟电脑」；③ 对照本章特点，说出哪些特点是本次实操能直接体会的（重点：资源虚拟化和透明化、资源池化、按需自助、快速弹性）。
▌ 准备：拿到 VMware 安装包
  1. 从教师下发的共享目录 / U 盘拷贝 VMware 安装程序到本机（如 VMware-player-xxxx.exe）。
  2. 确认本机是 64 位 Windows、剩余磁盘空间 ≥ 20GB。
▌ 第一步：安装 VMware
  1. 双击安装程序，按向导「下一步 → 接受协议 → 典型安装 → 完成」。
  2. 安装结束双击桌面图标能打开 VMware 窗口，即安装成功。
预期：桌面上多了「VMware」图标，这是承载所有虚拟电脑的「母体」。
▌ 第二步：新建第一台虚拟机（按需分配资源）
  1. 点「创建新虚拟机」→ 选「典型」→「稍后安装操作系统」。
  2. 客户机操作系统选 Linux，版本选 Ubuntu（或其他教师指定系统）。
  3. 给虚拟机起名（如 cloud-vm-1），磁盘大小填 20GB，勾选「将虚拟磁盘拆分成多个文件」。
  4. 在「自定义硬件」里把 内存设 2GB、处理器 1 核，确认后点「完成」。
体会：你刚从物理机的资源池里「切」出 2GB 内存 + 1 核 CPU 给这台虚拟电脑——这就是按需自助、资源池化。
▌ 第三步：启动虚拟机，看「多出来的一台电脑」
  1. 选中刚建的虚拟机，点「开启此虚拟机」。（若无系统镜像，进到 BIOS / 安装界面即可，重点是看到它独立运行）
  2. 若已装入 Linux，进入后依次执行下面命令，观察输出：
uname -a # 看这台「虚拟电脑」的内核 free -m # 看它分到的内存（应≈2GB） lscpu | head # 看它分到的 CPU
讨论：你并没有买第二台机器，却在原电脑里跑出了一台独立的「电脑」——它看不见底层硬件，只看到虚拟化层给的设备。这对应资源虚拟化和透明化。
▌ 第四步：再建第二台（一机变多机 = 快速弹性）
  1. 重复第二步，新建 cloud-vm-2，配置改成 2 核 4GB。
  2. 现在同一台物理机上同时有 2 台虚拟机，在 VMware 左侧列表能看到它们并列运行。
  3. 讨论：业务高峰时再「切」出几台、低谷时释放——对应云计算哪个特点？
预期：能说出「按需切出 / 释放多台虚拟机」，对应快速弹性（高可伸缩）。
▌ 第五步：回扣本章特点
  1. 对照教材本章列出的特点，圈出本次实操能直接体会的 4 个：资源虚拟化和透明化、资源池化、按需自助、快速弹性。
  2. 教师投屏总结：VMware 把一台物理机虚拟成资源池，这正是云计算「底层资源池化 + 上层按需取用」的最小化缩影。
验收清单：
  • VMware 安装成功，能打开窗口
  • 新建至少 1 台虚拟机（Linux），配置过内存 / CPU
  • 启动过虚拟机，执行过 uname / free 命令
  • 能说清：资源虚拟化 / 资源池化 / 按需自助 / 快速弹性 各自对应刚才哪个操作
机房提示：① 若学生机无安装权限或配置偏低，改为教师机投影演示安装 + 新建虚拟机，学生在自己机用教师下发的离线安装包完成；② 机房已预装 VMware 则跳过「第一步」直接新建虚拟机；③ 无 Linux 镜像时，进到安装界面 / BIOS 即可，重点在体会虚拟化而非装完系统；④ 下课前退出 VMware、关闭虚拟机。
