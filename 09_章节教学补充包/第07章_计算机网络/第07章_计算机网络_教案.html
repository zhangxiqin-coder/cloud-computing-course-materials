第7章 计算机网络 · 教案

教材：《云计算基础技术与应用(第2版)(微课版)》ISBN 978-7-115-66457-0

一、教学目的
  1. 理解云计算与计算机网络的关系——云本质上就是「跑在网络上的计算」，网络是云的地基。
  2. 掌握 TCP / IP 体系结构，理解 TCP 的连接管理（三次握手建立、四次挥手断开）与 UDP 的区别。
  3. 理解 IP 地址的作用、IPv4 地址分类与 IPv6 的由来。
  4. 第 3 课时用 Wireshark 抓取真实数据包，观察 TCP 三次握手，第 4 课时独立完成本章随堂练习。
二、重点、难点及处理方法

教学重点：

  1. TCP / IP 体系及各层作用。
  2. TCP 三次握手与四次挥手的过程与意义。
  3. IPv4 地址分类、IP 地址的作用；TCP 与 UDP 的核心区别。

教学难点：

  1. 三次握手 / 四次挥手的状态变化较抽象，学生易记成「两次」或顺序错乱。
  2. IPv4 地址分类（A/B/C 类）与子网概念容易混。
  3. TCP（可靠、面向连接）与 UDP（不可靠、无连接）的取舍场景难理解。

处理方法：

  • 用「打电话」比喻三次握手（拨号→响铃→接听）与四次挥手（挂断的来回确认），把抽象过程具象化。
  • 用「寄挂号信（TCP）vs 寄平信（UDP）」比喻可靠与不可靠的差异，落到视频通话 / 直播用 UDP、网页 / 下载用 TCP。
  • 第 3 课时用 Wireshark 抓包，让学生「亲眼看到」三次握手的 SYN / SYN+ACK / ACK 三个包，把名词变成画面。
三、教具

机房电脑 + 多媒体投影 Wireshark 抓包软件（教师分发安装，或教师机投影演示） 黑板 +「TCP 三次握手 / 四次挥手」时序图 IPv4 地址分类速查表（A/B/C 类范围）

四、课时分配

1、 讲课：云计算和计算机网络 + TCP / IP 体系 + TCP 连接管理（1 课时）
2、 讲课：IP（地址分类 / IPv6）+ UDP（1 课时）
3、 实战：Wireshark 抓取数据包，观察 TCP 三次握手（1 课时）
4、 随堂练习 + 讲解练习情况（1 课时）

五、作业

1、 完成随堂练习中当场未做完的题目（课本第 7 章「思考与练习」原题，教师投影题目或印发，学生纸上作答）。
2、 用一句话 + 一个生活例子说明 TCP 与 UDP 的区别，并指出微信发文字、看直播分别更像哪一种。
3、 整理第 3 课时抓包看到的「三次握手三个包」名称（SYN / SYN+ACK / ACK）。

六、教学过程
1
讲课：云与网络 + TCP/IP + TCP 连接管理
教材原版 PPT 第7章 4–36 页 ｜ 90 分钟
环节教学活动
引入教师：提问「没有网络，云还能叫云吗？你点的云盘文件是怎么到你屏幕上的？」引出「网络是云的地基」。
讲解教师：讲云计算和计算机网络的关系、TCP / IP 体系结构（应用层 / 传输层 / 网络层 / 网络接口层）及各层职责。
讲解教师：重点讲 TCP——面向连接、可靠传输，连接靠「三次握手」建立、断开靠「四次挥手」。用「打电话」比喻（拨号→响铃→接听 / 挂断的来回确认），在黑板画出 SYN、SYN+ACK、ACK 时序。
互动师生：全班口头接龙，每人接一句三次握手的下一步（教师起头「客户端发 SYN」，学生依次接「服务端回 SYN+ACK」「客户端回 ACK」），加固顺序记忆。
收口教师：小结 TCP/IP 与三次握手；预告下节课讲 IP 与 UDP，之后用 Wireshark 亲眼验证握手。
2
讲课：IP（地址分类 / IPv6）+ UDP
教材原版 PPT 第7章 37–74 页 ｜ 90 分钟
环节教学活动
引入教师：提问「信封上的地址用来干嘛？网络里数据包的『地址』是什么？」铺垫 IP。
讲解教师：讲 IP 的作用与 IPv4 地址分类（A / B / C 类范围与用途）、IP 地址的构成；讲 IPv6 出现的背景（地址耗尽）。配合「IPv4 地址分类速查表」。
讲解教师：讲 UDP——无连接、不可靠但快，适合实时音视频；对比 TCP 与 UDP 的取舍。用「寄挂号信 vs 寄平信」比喻，落到场景（网页 / 下载 = TCP，直播 / 语音 = UDP）。
互动师生：教师把「TCP vs UDP」对照表画在黑板，请学生口头补全（是否连接、是否可靠、典型应用），同步点破易错点（直播用 UDP 而非 TCP）。
收口教师：一句话总结 IP 管地址、TCP / UDP 管传输；点明下节课抓包看握手。
3
实战：Wireshark 抓取数据包，观察 TCP 三次握手
教材原版 PPT 第7章 75–77 页 ｜ 90 分钟
环节教学活动
布置教师：说明实战目标——用 Wireshark 抓取一次网页访问的网络包，在真实数据里找到 TCP 三次握手，把课堂画的时序图变成「亲眼所见」。Wireshark 由教师统一分发安装；机房若不可安装则改用教师机投影演示，学生观察分析。
实操电脑学生（分步完成）：
① 打开 Wireshark，选择网卡开始抓包；
② 浏览器访问一个 http 网站，制造流量；
③ 停止抓包，用过滤器 tcp.flags.syn==1 找到握手包；
④ 对照黑板时序图，确认看到 SYN、SYN+ACK、ACK 三个包；
⑤ 再找一两个 UDP 包，感受「无连接」。
巡堂教师：走动答疑，收集典型问题（如抓不到包、过滤器不会用），投屏演示；无安装权限的机位由教师统一投影，学生记录观察结果。
收口教师：请 1–2 组展示抓到的三次握手截图，点出「课本上的 SYN / SYN+ACK / ACK 就在你屏幕上」。要求每人记三个包名进笔记。
4
随堂练习 + 讲解练习情况
课本第7章「思考与练习」原题（教师投影 / 印发）｜ 90 分钟
环节教学活动
练习学生：完成课本第 7 章「思考与练习」原题（教师投影题目或印发，学生作答于作业本）。教师计时，约 35–40 分钟独立完成。
收看教师：巡堂收看完成情况，标记错误率高的题目（通常集中在三次握手 / 四次挥手、TCP vs UDP、IPv4 分类）。
讲解教师：挑选错误率最高的 6–8 题重点讲解，公布答案要点，让学生对照订正。
收口教师：回扣本章易错点做总结；未做完的题作为作业补完。
七、课后小结
人工智能241班：应到 42 人，实到 42 人。课时 1–2 TCP/IP 体系与 IP 地址分类达成度较好，打电话比喻学生接受快；三次握手 / 四次挥手状态顺序、TCP vs UDP 取舍仍是难点，需在抓包后二次回扣。课时 3 Wireshark 实战多数抓到握手包（约 3 组因无安装权限改看教师机演示），「眼见为实」效果好。课时 4 随堂练习握手类题正确率约 76%，UDP 场景题失分较多，已现场重讲。下次：握手时序图提前发，抓包前先空讲一遍过滤命令。

（按实际授课班级填写：到课情况、目标达成度、随堂练习正确率、易错点是否讲透、下次调整建议）
