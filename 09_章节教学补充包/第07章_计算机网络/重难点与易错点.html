第 7 章 · 计算机网络
重难点与易错点

对应 教材 PPT：7.计算机网络.pptx｜课本 7.8 思考与练习 p.105

一、本章重点（必须掌握）

重点1
TCP/IP 参考模型分四层：应用层、传输层、网络层、网络接口层，各层有典型协议。
重点2
IP 地址分 A/B/C 三类：A 类 1–126，B 类 128–191，C 类 192–223；网络号 + 主机号组成完整地址。
重点3
TCP 与 UDP 都工作于传输层：TCP 面向连接、可靠、有流量/拥塞控制；UDP 无连接、开销小、效率高、不保证可靠。
重点4
TCP 三次握手：客户端 SYN → 服务器 SYN-ACK → 客户端 ACK；四次挥手用于可靠释放连接。
重点5
IPv4 地址枯竭催生 IPv6：IPv6 地址空间巨大、首部更简洁、内置安全与移动性支持。

二、本章难点（讲慢一点、配比喻）

难点1
TCP 三次握手、四次挥手的具体报文顺序容易记混，需要结合状态图分阶段讲解。
难点2
IP 地址分类不能只看位数，要结合第一个十进制数判断 A/B/C 类，再确定网络号与主机号。
难点3
流量控制（端到端，接收方控制发送方速率）与拥塞控制（全局，防止网络过载）目标与机制不同。

三、易错点（学生常错，务必提前点破）

易错1
把 TCP/UDP 放到网络层——两者实际都在传输层，网络层跑的是 IP。
易错2
认为 IP 提供可靠传输——IP 是无连接、不可靠的，可靠性由上层 TCP 保证。
易错3
判断 IP 类别时只看子网掩码或位数，忽略第一个字节范围。
易错4
把「三次握手」理解为「多余」——其实是为了同步序列号并防止历史重复连接。
易错5
路由器、交换机、中继器、调制解调器混用：企业内网与外网互联必须用路由器做三层转发。
教师提示：建议把「易错点」单独投一屏，讲完知识点后立刻点破，比事后订正有效得多。
