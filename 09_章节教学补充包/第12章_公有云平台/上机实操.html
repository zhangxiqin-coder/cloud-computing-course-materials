上机实操指导

机房环境：可上网、不可安装软件，全部实操基于网页 / 在线工具 / 系统自带命令

机房纪律：① 一律不安装任何软件，网站要求下载客户端时点「网页版」；② 涉及云厂商页面只看不买，绝不点付款；③ 下课前必须退出登录，浏览器问「是否保存密码」一律选「从不」。
实验一：三大公有云官网产品对比（阿里云 ECS / 腾讯云 CVM / 华为云 ECS）
目标：在浏览器里逛主流公有云官网，认识云服务器产品，理解「买硬件」变成「租资源」。
操作步骤：
  1. 打开阿里云 ECS 产品页、腾讯云 CVM、华为云 ECS 三个官网产品页。
  2. 各看一遍「规格 / 价格 / 特点」，填一张对比表：厂商 / 产品名 / 计费方式 / 典型规格 / 一句话特点。
  3. 重点找「弹性伸缩」「负载均衡」这两个功能在哪一页、怎么描述。
  4. 讨论：三家都强调「弹性」，这和教材说的云服务器特点是否一致？
验收清单：
  • 看过至少 3 家云服务器产品页
  • 对比表填完 3 行
  • 能指出弹性伸缩/负载均衡在哪
打不开 / 完不成：只看官网介绍，不注册、不下单、不填真实信息。
实验二：浏览器里走一遍云服务器创建流程（不下单，可用免费试用额度）
目标：理解云服务器的「创建—网络—登录方式」配置，体会控制台即 B/S 形态的管理接口。
操作步骤：
  1. 进入任意一家云控制台的「创建实例」流程页（不实际下单）。
  2. 依次看：选地域/可用区、选规格、选镜像（系统盘）、配置网络与安全组、设置登录方式（密钥/密码）。
  3. 找到「弹性伸缩」和「负载均衡」的配置入口截图保存。
  4. 若学校有免费试用额度，可在教师指导下实开一台最小规格实例，ssh 登录看一眼后立刻释放。
验收清单：
  • 走过创建实例的配置步骤
  • 截图保存弹性伸缩/负载均衡入口
  • 能说出登录方式有哪几种
打不开 / 完不成：严禁实际下单付费；如有试用额度，演示结束立即释放实例。
实验三：对象存储 vs 块存储 对照（云控制台产品介绍）
目标：把最易混的两种云存储形式用对照表钉死。
操作步骤：
  1. 在云官网看对象存储（如 OSS/S3）与块存储（如 EBS/EVS）的产品介绍页。
  2. 填对照表：存储形式 / 访问方式 / 能否格式化挂载 / 典型场景（各 3 条）。
  3. 讨论：为什么「系统盘」要用块存储，而「图片/视频资源」更适合对象存储？
验收清单：
  • 看过两种存储的产品介绍
  • 对照表填完
  • 能说出二者适用场景差异
打不开 / 完不成：只看介绍，不创建存储桶、不产生费用。
