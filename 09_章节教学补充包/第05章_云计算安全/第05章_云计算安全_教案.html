第5章 云计算安全 · 教案

教材：《云计算基础技术与应用(第2版)(微课版)》ISBN 978-7-115-66457-0

一、教学目的
  1. 认识云计算面临的安全威胁，理解「云计算和信息安全」的关系——上云后数据离开本地，安全成为生命线。
  2. 理解密码学基础：密码技术与密码学的概念、对称密码与非对称密码的区别、常见密码算法（DES / AES / RSA / 椭圆曲线 / 多变量公钥）。
  3. 理解公钥基础设施（PKI）与身份和访问管理（IAM）的作用，掌握哈希（Hash）的不可逆与「雪崩效应」。
  4. 第 3 课时通过「云安全三连击」亲手体验加密（密钥概念）、完整性校验（MD5）、身份认证（HTTPS 证书），第 4 课时独立完成本章随堂练习。
二、重点、难点及处理方法

教学重点：

  1. 密码技术与密码学的概念，区分加密（保密）、哈希（完整性）、证书（身份）三类安全基石。
  2. 对称密码与非对称密码的核心区别——密钥是否公开、各自适合什么场景。
  3. 哈希的不可逆与「改一个字符结果全变」；PKI / 数字证书如何支撑身份认证。

教学难点：

  1. 对称密码与非对称密码容易混淆：谁用一把钥匙、谁用一对钥匙、为什么需要非对称。
  2. 哈希「不可逆」与「雪崩效应」较抽象，学生易误以为能从 MD5 反推原文。
  3. PKI 信任链（CA → 证书 → 浏览器信任）概念链条长。

处理方法：

  • 用「同一把锁 vs 一把公开锁 + 一把私有钥匙」比喻对称（一把密钥）与非对称（公钥加密、私钥解密）。
  • 用「录指纹」比喻哈希——指纹固定且唯一，但绝不可能从指纹反推出整个人；用改一个字母 MD5 全变的现象讲「雪崩效应」。
  • 把「加密 / 完整性 / 身份认证」三件事做成一张对照表，逐列请学生口头补全，提前点破易错点。
三、教具

机房电脑 + 多媒体投影 在线工具：在线 MD5 计算页（如 emn178.github.io/online-tools）、证书查看演示页 黑板 +「加密 / 完整性 / 身份认证」三列对照表 凯撒密码练习纸（A→D 后移 3 位）

四、课时分配

1、 讲课：云计算和信息安全 + 密码技术和密码学 + 对称密码和公钥密码（1 课时）
2、 讲课：密码算法（DES / AES / RSA / 椭圆曲线 / 多变量公钥）+ 公钥基础设施和身份访问管理（PKI / IAM）+ 哈希（1 课时）
3、 实战：云安全三连击——凯撒密码、在线 MD5、查看 HTTPS 证书（1 课时）
4、 随堂练习 + 讲解练习情况（1 课时）

五、作业

1、 完成随堂练习中当场未做完的题目（课本第 5 章「思考与练习」原题，见补充包「随堂练习.html」）。
2、 用一句话分别说明「加密、哈希、证书」各自解决什么安全问题，并各举一个生活例子。
3、 整理第 3 课时「云安全三连击」的 1 条操作记录（如「改一个字母，MD5 值从 xx 变成 yy」）。

六、教学过程
1
讲课：云安全概述 + 密码学基础
教材原版 PPT 第5章 4–25 页 ｜ 90 分钟
环节教学活动
引入教师：提问「你的照片存在云盘，不在自己电脑里，谁保证别人看不到、改不了？」引出「上云后安全是生命线」。
讲解教师：讲云计算和信息安全的关系——数据离开本地、集中到云端，面临窃取、篡改、抵赖等新威胁；安全目标可归为保密、完整、可用、可认证。
讲解教师：讲密码技术和密码学概念——密码学是研究加密、解密、认证的学科；再讲对称密码（加解密用同一把密钥，快但密钥分发难）与非对称密码（一对密钥，公钥加密、私钥解密，解决分发问题）。
互动师生：全班口头接龙，每人说一个「需要保密 / 需要确认身份」的日常生活场景（寄信封口、门禁卡、签名），教师快速归类到黑板「保密 / 完整 / 认证」三列。
收口教师：小结三类安全基石；预告下节课讲具体算法与 PKI / 哈希，之后亲手做一次「云安全三连击」。
2
讲课：密码算法 + PKI/IAM + 哈希
教材原版 PPT 第5章 26–57 页 ｜ 90 分钟
环节教学活动
讲解教师：按表格过一遍算法——对称：DES（56 位，已不安全）、AES（主流）；非对称：RSA、椭圆曲线（ECC，短密钥高强度）、多变量公钥。强调「没有绝对安全，只有够用」。
讲解教师：讲公钥基础设施（PKI）与身份和访问管理（IAM）——PKI 由 CA（证书颁发机构）、证书、密钥组成，解决「你怎么证明你是你」；IAM 解决「你能访问哪些资源」。
讲解教师：讲哈希（Hash）——把任意长度输入变成固定长度摘要，不可逆、且「改一个字符结果全变」（雪崩效应）。用「录指纹」比喻：固定唯一但不可反推。
互动师生：教师把「加密 / 完整性 / 身份认证」对照表画在黑板，逐行请学生口头补全（对称 vs 非对称、哈希 vs 加密、PKI 解决什么），同步点破易错点（哈希不可逆、非对称慢但解决分发）。
收口教师：一句话串起三类安全基石；点明下节课用网页工具亲手体验，把名词变成操作。
3
实战：云安全三连击（加密 · 完整性 · 身份认证）
教材原版 PPT 第5章 58–63 页 ｜ 衔接补充包「上机实操.html」｜ 90 分钟
环节教学活动
布置教师：说明实战目标——亲手做一次加解密（密钥概念）、看一次哈希雪崩（完整性）、查一次网站证书（身份认证），把安全从概念变成看得见、摸得着的东西。全程基于网页 / 在线工具，不安装任何软件。
实操电脑学生（分步完成，详细见补充包「上机实操.html」）：
① 凯撒密码：约定字母后移 3 位（A→D），把 HELLO 加密成 KHOOR，同桌互出单词加解密——理解「3 就是密钥」；
② 在线 MD5：输入 cloud 记下值，改一个字符成 clouds 对比——结果完全不同（雪崩效应），再输入 cloud 确认值不变（不可逆）；
③ 查看 HTTPS 证书：打开 https 网站，点地址栏锁形图标看证书，记下颁发者 CA / 有效期 / 加密算法，再对比一个 http 网站地址栏提示。
巡堂教师：走动答疑，收集典型问题（如 MD5 工具打不开、证书菜单位置不同），投屏演示处理：MD5 可用命令提示符 certutil -hashfile 文件名 MD5 替代；证书可在浏览器设置的安全页查看。
收口教师：请 1–2 组展示「改一个字符 MD5 前后对比」，点出「加密保保密、哈希保完整、证书保身份」三者缺一不可。要求每人留 1 条操作记录进笔记。
4
随堂练习 + 讲解练习情况
用补充包「随堂练习.html」（课本原题）｜ 90 分钟
环节教学活动
练习学生：完成补充包「随堂练习.html」中的课本第 5 章「思考与练习」原题（教师投影题目或印发，学生作答于作业本）。教师计时，约 35–40 分钟独立完成。
收看教师：巡堂收看完成情况，标记错误率高的题目（通常集中在对称 / 非对称区分、哈希性质、PKI 作用）。
讲解教师：挑选错误率最高的 6–8 题重点讲解，公布答案要点（参考补充包「随堂练习_答案.html」），让学生对照订正。
收口教师：回扣本章易错点做总结；未做完的题作为作业补完。
七、课后小结
人工智能241班：应到 38 人，实到 38 人（全勤）。课时 1–2 云安全三类基石与对称 / 非对称区别达成度较好，「锁与钥匙」比喻学生接受快；哈希不可逆、PKI 信任链仍是难点，需在实操后二次回扣。课时 3 云安全三连击多数完成凯撒 + MD5，个别证书菜单位置找不到改用教师机演示。课时 4 随堂练习对称 / 非对称类题正确率约 78%，哈希性质失分较多，已现场重讲。下次：三类安全对照表提前发，课堂多留填表时间。
