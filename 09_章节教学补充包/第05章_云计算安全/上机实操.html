第 5 章 · 云计算安全
云安全实战课堂实操

机房环境：可上网、不可安装软件，全部实操基于网页 / 在线工具。本章三个短活动串起安全三大基石：加密、完整性、身份认证。

机房纪律：① 一律不安装任何软件，网站要求下载客户端时点「网页版」；② 涉及云厂商页面只看不买，绝不点付款；③ 下课前必须退出登录，浏览器问「是否保存密码」一律选「从不」。
云安全三连击（对应教材实战项目）
目标：亲手做一次加解密（密钥概念）、看一次哈希「雪崩效应」（完整性）、查一次网站证书（身份认证），把安全从概念变成看得见、摸得着的东西。
▌ 第一击：凯撒密码——最古老的加密（密钥概念）
  1. 约定规则：每个字母向后移 3 位（A→D、B→E、…、X→A），这个「3」就是密钥。
  2. 把 HELLO 加密，写出结果 KHOOR。
  3. 同桌互相出一个单词（4–6 个字母），对方加密后再由你解密。
  4. 讨论：如果不知道「3」这个数字，能解开吗？最多试几次？
预期：能说出「后移 3 位」就是密钥，且最多试 25 次就能破解——理解「密钥」与「弱加密」。
▌ 第二击：在线 MD5——改一个字符结果全变（完整性校验）
  1. 打开 https://emn178.github.io/online-tools/md5.html。
  2. 输入 cloud，记下它的 MD5 值。
  3. 只改一个字符，输入 clouds，对比两个 MD5 值——完全不一样。
  4. 再输入 cloud 确认结果不变，体会「同样输入必然同样输出，但无法反推原文」。
预期：亲眼看到哈希的「雪崩效应」与不可逆，理解完整性校验的原理。
▌ 第三击：查看网站的 HTTPS 证书（身份认证 / 加密通信）
  1. 用浏览器打开 https://www.qq.com（注意是 https）。
  2. 点地址栏左侧的锁形图标 → 查看证书（连接是安全的 → 证书有效）。
  3. 找三项并记下来：颁发者（CA）是谁 / 有效期到哪天 / 用的是什么加密算法。
  4. 再打开一个 http://（非 https）的网站，对比地址栏提示有何不同。
预期：亲眼看到数字证书和 CA，把 PKI 从名词变成看得见的东西。
验收清单：
  • 亲手加密过 2 个以上单词，能说出「后移 3 位」就是密钥
  • 算出过 2 个以上的 MD5 值，亲眼看到改一个字符结果全变
  • 找到证书的颁发者 CA 并记下有效期
  • 能说清 https 与 http 地址栏提示的区别
打不开 / 完不成：① 凯撒密码不必纠结算法强度，重点在「密钥」二字；② MD5 工具若打不开，机房本机可用命令提示符输入 certutil -hashfile 文件名 MD5 替代；③ 证书菜单位置各浏览器略有差别，找不到就访问 chrome://settings/security 查看。
