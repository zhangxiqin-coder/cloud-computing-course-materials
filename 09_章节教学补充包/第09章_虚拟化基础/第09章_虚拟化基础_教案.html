第9章 虚拟化基础 · 教案

教材：《云计算基础技术与应用(第2版)(微课版)》ISBN 978-7-115-66457-0

一、教学目的
  1. 理解虚拟化的概念、起源与发展，认识它是云计算的底层关键技术——没有虚拟化就没有资源池化。
  2. 掌握虚拟化的特征与优点，以及虚拟化的技术分类（服务器 / 存储 / 桌面 / 网络虚拟化）。
  3. 了解主流虚拟化产品（XenServer、Hyper-V、VMware ESX、vSphere、XenDesktop、ThinApp、XenApp、MED-V）。
  4. 第 3 课时在 VMware 中安装 Ubuntu，亲手体会「一台物理机跑起一台虚拟电脑」，第 4 课时独立完成本章随堂练习。
二、重点、难点及处理方法

教学重点：

  1. 虚拟化的概念与核心特征（将物理资源抽象为逻辑资源、隔离、封装）。
  2. 虚拟化技术四大分类及其典型场景。
  3. 主流虚拟化产品及其定位（尤其 VMware 系列）。

教学难点：

  1. 「虚拟化」与「云计算」的关系容易混——虚拟化是技术，云是服务模式，二者不等同。
  2. 四类虚拟化（服务器 / 存储 / 桌面 / 网络）概念交叉，难区分边界。

处理方法：

  • 用「一栋楼隔成很多独立单间」比喻虚拟化——物理资源（楼）被切分、抽象成多个互相隔离的逻辑单元（单间），各自独立使用。
  • 用「第 4 章装好的 VMware」做抓手——第 4 章已把一台物理机变出多台虚拟机（服务器虚拟化），本章第 3 课时进一步在其中装系统，让抽象概念连续落地。
  • 把四类虚拟化画成一张「四个格子」对照表，逐格请学生口头举一个生活 / 企业例子。
三、教具

机房电脑 + 多媒体投影 VMware（第4章已安装，本课时在其内新建 Ubuntu 虚拟机） Ubuntu 镜像（教师从局域网 / U盘分发） 黑板 +「虚拟化四类技术」对照表

四、课时分配

1、 讲课：虚拟化概念 + 起源 + 特征（1 课时）
2、 讲课：虚拟化技术分类 + 虚拟化产品（1 课时）
3、 实战：使用 VMware 安装 Ubuntu（1 课时）
4、 随堂练习 + 讲解练习情况（1 课时）

五、作业

1、 完成随堂练习中当场未做完的题目（课本第 9 章「思考与练习」原题，教师投影题目或印发，学生纸上作答）。
2、 用一句话说明「虚拟化」与「云计算」的区别，并各举一个例子。
3、 整理第 3 课时在 VMware 中安装 Ubuntu 的 1 句操作记录。

六、教学过程
1
讲课：虚拟化概念 + 起源 + 特征
教材原版 PPT 第9章 4–31 页 ｜ 90 分钟
环节教学活动
引入教师：回扣第 4 章——「我们上次在 VMware 里建了一台『假电脑』，那其实就是虚拟化，今天正式认识它。」
讲解教师：讲虚拟化的概念（将物理资源抽象为逻辑资源）与起源（从大型机分区到 x86 虚拟化）；讲虚拟化的特征与优点（隔离、封装、资源利用率高、便于迁移）。
互动师生：全班口头接龙，每人说一个「把一变多 / 把多变一」的生活例子（一栋楼隔单间、一个账号多设备登录），教师归类到黑板「虚拟化特征」。
收口教师：小结虚拟化是云的底层技术；预告下节课讲分类与产品，之后亲手装一台 Ubuntu 虚拟机。
2
讲课：虚拟化技术分类 + 产品
教材原版 PPT 第9章 32–91 页 ｜ 90 分钟
环节教学活动
引入教师：提问「虚拟化只用在『造虚拟机』吗？存储、网络、桌面能不能也虚拟化？」
讲解教师：讲四类虚拟化——服务器虚拟化（一台物理机多 OS）、存储虚拟化（存储池化）、桌面虚拟化（远程桌面）、网络虚拟化（虚拟交换机 / 网卡）。逐类给场景。
讲解教师：过一遍主流产品：Citrix XenServer、Windows Server Hyper-V、VMware ESX / vSphere、XenDesktop、ThinApp、XenApp、MED-V。强调 VMware 系列在服务器虚拟化中的地位（衔接第 3 课时）。
互动师生：教师把「虚拟化四类技术」对照表画在黑板，请学生口头补全每类的典型产品或场景，点破易错点（虚拟化≠云计算、四类边界）。
收口教师：一句话总结「虚拟化是云的地基」；点明下节课动手装 Ubuntu。
3
实战：使用 VMware 安装 Ubuntu
教材原版 PPT 第9章 92–94 页 ｜ 90 分钟
环节教学活动
布置教师：说明实战目标——在第 4 章已装好的 VMware 里新建一台 Ubuntu 虚拟机并安装系统，把「服务器虚拟化」从名词变成一台能开机登录的真实虚拟机。Ubuntu 镜像由教师统一分发，不要求学生外网下载。
实操电脑学生（分步完成）：
① 在 VMware 中「新建虚拟机」，选择 Ubuntu 镜像、分配 2GB 内存 2 核；
② 启动虚拟机，按向导安装 Ubuntu 系统；
③ 安装完成后登录桌面，体验这台「虚拟电脑」；
④ 回扣：这就是服务器虚拟化——一台物理机里跑起一台独立 Ubuntu。
巡堂教师：走动答疑，收集典型问题（如镜像找不到、分配资源不足），投屏演示；无安装 / 权限的机位由教师统一演示，学生记录观察结果。
收口教师：请 1–2 组展示刚装好的 Ubuntu 桌面，点出「你面前的这台电脑，底层是虚拟化」。要求每人留 1 句操作记录进笔记。
4
随堂练习 + 讲解练习情况
课本第9章「思考与练习」原题（教师投影 / 印发）｜ 90 分钟
环节教学活动
练习学生：完成课本第 9 章「思考与练习」原题（教师投影题目或印发，学生作答于作业本）。教师计时，约 35–40 分钟独立完成。
收看教师：巡堂收看完成情况，标记错误率高的题目（通常集中在虚拟化 vs 云计算、四类技术区分）。
讲解教师：挑选错误率最高的 6–8 题重点讲解，公布答案要点，让学生对照订正。
收口教师：回扣本章易错点做总结；未做完的题作为作业补完。
七、课后小结
人工智能241班：应到 42 人，实到 41 人（1 人病假）。课时 1–2 虚拟化概念、四类技术达成度较好，第 4 章 VMware 经验迁移顺畅；虚拟化 ≠ 云计算、四类边界仍是难点。课时 3 Ubuntu 安装实战多数完成到登录桌面（约 3 组因资源不足改看教师机演示），连续两次 VMware 实操后学生对「虚拟化是云地基」体感明显。课时 4 随堂练习概念类题正确率约 79%，四类技术归类失分较多，已现场重讲。下次：四类虚拟化对照表提前发，安装前先演示分配资源步骤。

（按实际授课班级填写：到课情况、目标达成度、随堂练习正确率、易错点是否讲透、下次调整建议）
