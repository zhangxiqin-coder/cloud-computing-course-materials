第 9 章 · 虚拟化基础
上机实操指导

机房环境：可上网、不可安装软件，全部实操基于网页 / 在线工具 / 系统自带命令

机房纪律：① 一律不安装任何软件，网站要求下载客户端时点「网页版」；② 涉及云厂商页面只看不买，绝不点付款；③ 下课前必须退出登录，浏览器问「是否保存密码」一律选「从不」。
实验一：网页里跑 Linux 虚拟机（体验服务器虚拟化）
目标：不安装任何软件，在浏览器里体验「一台物理机变多台虚拟机」。
操作步骤：
  1. 打开 https://bellard.org/jslinux/。
  2. 等待 30–60 秒，命令行出现后执行 uname -a。
  3. 再开一个浏览器标签页，再打开一次，同时运行两台「虚拟机」。
  4. 讨论：你的电脑没有安装虚拟机软件，为什么能跑起一个完整的 Linux？
验收清单：
  • 网页中出现 Linux 命令行
  • 执行过 uname -a
  • 同时打开过 2 个标签页
打不开 / 完不成：这是浏览器模拟的 Linux，原理与真实虚拟化相同，只是运行在 JS 层。
实验二：虚拟化产品市场调研
目标：认识主流虚拟化产品，理解服务器/桌面/个人三个层级。
操作步骤：
  1. 打开 VMware 中国官网 https://www.vmware.com/cn.html，看 vSphere/ESXi 产品。
  2. 打开 VirtualBox 官网 https://www.virtualbox.org/，看个人免费虚拟化。
  3. 用搜索引擎查「华为 FusionSphere」或「Citrix 桌面虚拟化」，填表：产品名 / 类型 / 收费方式 / 典型用户。
验收清单：
  • 看过 VMware 和 VirtualBox 两款产品
  • 至少再查一款国产或桌面虚拟化产品
  • 表格填完 3 行
打不开 / 完不成：只看官网介绍，不下载安装。
实验三：虚拟化收益计算小练习
目标：用量化方式理解虚拟化如何节省物理空间和成本。
操作步骤：
  1. 假设一家企业原来有 20 台物理服务器，每台占地 2U、功耗 300W。
  2. 引入虚拟化后，按 5:1 整合，只需要 4 台物理机承载同样业务。
  3. 计算：① 机柜空间从 40U 降到 8U；② 功耗从 6000W 降到 1200W。
  4. 讨论：除了空间和电费，虚拟化还可能在哪些方面降低成本？
验收清单：
  • 算出新旧物理机数量
  • 算出节省的机柜空间和功耗
  • 能说出至少 2 个其他收益
打不开 / 完不成：数字是估算，重点是理解整合比例带来的收益。
